## Introduction: A Neglected Real Need

When analyzing structures, we can use the subject-object method: establish my position (subject), analyze the other party (object), formulate strategy.

But reality often presents another situation:

**Company A and Company B are negotiating, and this negotiation affects my business, but I'm neither A nor B.**

**What I really need is: quickly judge how this external structure will evolve, and how it impacts my current situation.**

This chapter solves this problem.

---

## Section 1: Third-Party Perspective Under Subjectivity

### 1.1 Not Objectivity Worship

When I say "establish a third-party perspective," it's easy to be misunderstood as pursuing some "objective neutral" god's-eye view.

**Must clarify: This is not objectivity worship.**

The difference:

- **Objectivity worship**: Claims there exists a "true perspective" that transcends all subjects
- **Third-party under subjectivity**: Within my subjective cognition, construct an observation position to examine structural relationships

Analogy:

- You can simulate in your mind "how would I view this as an observer"
- This "observer" is still subjectively constructed by you
- But it provides a useful analytical position

**This is an operational mode of subjective cognition, not finding a god's-eye view.**

### 1.2 Natural Judgment of Superior-Subordinate Relations

When observing external structures from a virtual third-party position, the brain does something naturally: **judge who is in the superior position, who is in the subordinate position**.

**What is a superior-subordinate relationship?**

Not a value judgment (who is better), but **structural positional difference**:

- **Superior**: In a specific structure, the party controlling decision rights and dominating the rhythm
- **Subordinate**: In a specific structure, the party in a responsive position, passively adapting

**Why does the brain automatically judge superior-subordinate?**

Under specific intentions (usually consensual intentions), certain relationships make the brain automatically assign positions:

- Parent-child (daily care context): Parent is superior
- Platform-merchant: Usually platform is superior
- Creditor-debtor: Creditor is superior
- Scarce party-demanding party: Scarce party is superior

**Key cognition: Superior-subordinate relationships aren't absolute, they depend on specific intentions. If we arrange superior-subordinate relationships, we can stabilize the structure so analysis doesn't get confused.**

Same parent-child relationship:

- Daily care: Parent superior (decides what to eat, when to sleep)
- Property inheritance: Child superior (decides whether to accept, how to distribute)
- Elderly care decisions: Child superior (decides care methods, living arrangements)

### 1.3 Difference from Subject-Object Method

|Dimension|Subject-Object Method|Third-Party Perspective|
|---|---|---|
|**Premise**|I'm one participant|I'm external observer|
|**Operation**|Establish my position → other becomes object|No need to simulate any party, virtual observation position → judge superior-subordinate|
|**Purpose**|Guide my actions|Understand external structure and its impact|
|**Core Question**|"What should I do?"|"How will this structure evolve? What's the impact on me?"|

## Section 2: Superior-Subordinate Grouping and Four Compression Structures

### 2.1 Review of Six Dimensions

Any bilateral relationship can be expanded into six dimensions:

```
Superior (Object):
  Dimension 6: Attitude
  Dimension 5: Quality
  Dimension 4: Action

Subordinate (Subject):
  Dimension 3: Attitude
  Dimension 2: Quality
  Dimension 1: Action
```

**But six dimensions are too complex for quick judgment.**

### 2.2 Compression Logic of Superior-Subordinate Grouping

**Why superior-subordinate grouping?**

We mentioned earlier that arranging superior-subordinate relationships can stabilize structure and avoid analytical confusion. Specifically:

- **Fixed analytical framework**: Dimensions 1-3 are always subordinate, dimensions 4-6 are always superior
- **Unified compression method**: Once superior-subordinate is determined, compression rules can be applied
- **Easy comparison**: Multiple external structures can be judged using the same standard

Without fixing superior-subordinate, analysis gets stuck in endless debate of "Is A superior or B superior?"

**Core discovery: The brain automatically simplifies six dimensions during quick judgment.**

**Compression rule (based on observing actual thinking processes):**

- If two of three dimensions are +, overall judgment is +
- If two of three dimensions are -, overall judgment is -

Plain explanation: Ignore details, barely acceptable = acceptable, barely not working = not working, fully acceptable = working, totally not working = not working.

**Example: Chip Manufacturer A - Phone Manufacturer B**

```
Original six dimensions:
Phone Manufacturer B (subordinate):
  Action: Actively negotiating +
  Quality: Has purchasing power +
  Attitude: Abnormal negotiation attitude -

Chip Manufacturer A (superior):
  Action: Insufficient capacity -
  Quality: Insufficient technology -
  Attitude: Still cooperative +
```

**Superior-subordinate grouping compression:**

```
Subordinate overall: + (two +, one -)
Superior overall: - (two -, one +)

Compressed structure: +-
```

### 2.3 Four Basic Structural Lexicons

Based on overall judgment of superior-subordinate positions, we get four basic structures:

#### 2.3.1 Stable Win-Win (++)

**Characteristics:**

- Superior overall positive (has strength, has willingness)
- Subordinate overall positive (has capability, has cooperation)
- Both sides satisfied with current structure

**Common scenarios:**

- Mature supply chain relationships
- Stable employment relationships
- Long-term strategic cooperation

**Evolution direction:**

- Maintain status quo
- Gradually deepen
- Expand cooperation scope

**Risks:**

- External shocks (competitors, technological change)
- Internal complacency (both sides stop improving)

#### 2.3.2 Suppression Structure (-+)

**Characteristics:**

- Superior overall positive (has strength, has dominance)
- Subordinate overall negative (insufficient capability, dissatisfied attitude)
- Subordinate passively accepts

**Common scenarios:**

- Monopoly platform - small merchants
- Strong party A - weak party B
- Authoritative superior - powerless subordinate

**Evolution direction:**

- Subordinate seeks exit
- Subordinate unites to resist
- Subordinate waits for chance to overturn

**Stability conditions:**

- Subordinate has no exit option
- Superior provides sufficient value compensation
- Subordinate loses hope for change

#### 2.3.3 Imbalance Structure (+-)

**Characteristics:**

- Superior overall negative (insufficient strength, but occupies position)
- Subordinate overall positive (has strength, but position is lower)
- **Greatest structural tension**

**Common scenarios:**

- Traditional enterprise - new technology team
- Established supplier - emerging customer
- Senior but less capable manager - capable newcomer

**Evolution direction:**

- **High probability of inversion** (subordinate rises, superior falls)
- Superior quickly fills gaps
- Subordinate actively exits (seeks better position)

**Key judgment:**

- Inversion speed depends on **subordinate's external options**
- Superior maintains through **institutional barriers** (not capability)

**Case: Chip Manufacturer A - Phone Manufacturer B**

- Compressed to +-
- Judgment: Imbalance structure, chip manufacturer's superior position unstable
- Prediction: Phone manufacturer will seek alternative suppliers

#### 2.3.4 Collapse Structure (--)

**Characteristics:**

- Superior overall negative
- Subordinate overall negative
- Both sides dissatisfied

**Common scenarios:**

- Internal relationships in near-bankrupt companies
- Failed project teams
- Cooperation heading toward breakup

**Evolution direction:**

- Structure disintegrates
- Both sides exit
- Seek new structure

**Rescue conditions:**

- External force maintains (law, contract)
- Sudden positive change alters situation
- Third party intervenes to reorganize

### 2.4 Value of Superior-Subordinate Grouping

**Quickly identify external structure types**

- When scanning multiple external structures
- Need quick classification judgment
- Use four types to identify

**Provide evolution predictions**

- Stable win-win: Short-term unchanged
- Suppression structure: Subordinate seeks opportunity
- Imbalance structure: Possible inversion
- Collapse structure: About to disintegrate

**Guide observation focus**

- Imbalance structure: Focus on inversion timing
- Suppression structure: Focus on subordinate movements
- Stable win-win: Focus on external shocks

## Section 3: Foundation-Interaction-Target Compression

### 3.1 Discovery of Another Grouping Method

The same six-dimensional structure can also be grouped from another angle:

**Not by role position (superior-subordinate), but by event structure (time-causality)**

```
Foundation layer: Dimension 1+2 (subordinate's action and quality)
Interaction layer: Dimension 3+4 (contact surface of both sides)
Target layer: Dimension 5+6 (superior's state)
```

**Why group this way?**

This matches the brain's natural logic for processing cooperation/transaction events:

- **Premise**: How are the initiator's conditions?
- **Process**: How is the interaction quality?
- **Purpose**: How is the target object's state?

### 3.2 Regrouping the Chip Manufacturer Case

```
Original six dimensions:
Phone Manufacturer B:
  Action: Actively negotiating +
  Quality: Has purchasing power +
  Attitude: Abnormal negotiation attitude -

Chip Manufacturer A:
  Action: Insufficient capacity -
  Quality: Insufficient technology -
  Attitude: Still cooperative +
```

**Foundation-Interaction-Target grouping:**

```
Foundation layer (B's strength + action): ++ → +
Interaction layer (both sides' contact surface): -- → -
Target layer (A's state): -+ → +

Compressed structure: +-+
```

### 3.3 Interpreting +-+ Structural Lexicon

**+-+ is "Willing but Unable State" among the eight states**

Standard characteristics:

- First dimension (foundation/action): + (has foundation conditions)
- Second dimension (interaction/capability): - (currently blocked)
- Third dimension (target/attitude): + (target achievable)

**Mapping to case:**

- Good foundation (phone manufacturer has strength and willingness)
- Poor interaction (contact between both sides not smooth)
- Target viable (chip manufacturer has willingness though capability weak)

**Structural lexicon judgment:**

This is a "**has foundation, has willingness, but currently blocked**" situation, typical "want to succeed but can't."

**Prediction:**

- If interaction layer improves → cooperation may succeed
- If interaction layer worsens → even if foundation and target are good, will fail
- **Key bottleneck is interaction layer**

### 3.4 Comparison of Two Compression Methods

|Dimension|Superior-Subordinate Grouping|Foundation-Interaction-Target|
|---|---|---|
|**Grouping logic**|By role position|By event structure|
|**Perspective**|Observe power comparison|Observe whether event can succeed|
|**Compression result**|Two-dimensional (++/+-/-+/--)|Three-dimensional (one of eight states)|
|**Answers question**|Who has advantage? Will position change?|Can this succeed? Where's the bottleneck?|
|**Applicable scenario**|I'm external observer|I care about event outcome|

### 3.5 Dual-Perspective Comprehensive Judgment

**Complete analysis of chip manufacturer-phone manufacturer case:**

**Perspective 1 (Superior-subordinate grouping):**

- Compression result: +- (imbalance structure)
- Judgment: Chip manufacturer's superior position unstable, phone manufacturer may seek alternatives

**Perspective 2 (Foundation-interaction-target):**

- Compression result: +-+ (willing but unable state)
- Judgment: Cooperation has foundation and willingness, but current interaction poor

**Comprehensive conclusion:**

- Power comparison: Phone manufacturer has advantage
- Cooperation possibility: Viable but blocked
- **Key bottleneck: Interaction layer (contact quality between both sides)**

**Strategy recommendations:**

For Chip Manufacturer A:

1. Quickly improve interaction layer: Take initiative, improve communication
2. Acknowledge shortcomings: Frankly admit capacity and technology gaps, but give improvement timeline
3. Stabilize attitude: Maintain active cooperation (this is your only advantage)

For Phone Manufacturer B:

1. Don't over-suppress: Other party's attitude is okay, don't push them away
2. Build trust: Clearly state your real concerns
3. Give time: If other party can improve, this cooperation still has value

## Section 4: Core Insight—Grouping is Perspective

### 4.1 Theoretical Breakthrough

**The same six-dimensional structure can have multiple grouping methods, each representing an analytical perspective.**

Two known grouping methods:

**Method 1: Superior-Subordinate Grouping (role position)**

```
Superior: Dimension 4+5+6
Subordinate: Dimension 1+2+3
Result: Two-dimensional judgment (power comparison)
```

**Method 2: Foundation-Interaction-Target (event structure)**

```
Foundation: Dimension 1+2
Interaction: Dimension 3+4
Target: Dimension 5+6
Result: Three-dimensional judgment (one of eight states)
```

### 4.2 No "Correct" Grouping

**Key cognition:**

Like the same cube:

- From the front, it's a square
- From the side, it's a square
- From a corner, it's a hexagon

**The six-dimensional structure is that cube, grouping methods are observation angles.**

**There's no "only correct" grouping, only "intention-appropriate" grouping.** **When we use a certain grouping method as a fixed method, we can observe, record, analyze, summarize, reference, and use it.**

### 4.3 How to Choose Grouping Method

**Decision tree:**

**Question 1: What's my intention?**

- **Care about power comparison** → Use superior-subordinate grouping
    - Who will win?
    - Will position change?
    - Which side should I support?
- **Care about success possibility** → Use foundation-interaction-target
    - Can this succeed?
    - Where's the bottleneck?
    - How to advance?

**Question 2: What's my role?**

- **I'm external observer** → Superior-subordinate grouping more intuitive
- **I'm participant/facilitator** → Foundation-interaction-target more practical

**Question 3: What output do I need?**

- **Need quick classification (four types)** → Superior-subordinate grouping
- **Need to invoke eight-state lexicon** → Foundation-interaction-target

**Practical advice: View both**

1. Use superior-subordinate grouping, quickly judge power comparison
2. Use foundation-interaction-target, judge whether thing can succeed
3. Combine both perspectives, formulate strategy

## Section 5: External Structure Impacts My Situation

### 5.1 Three-Layer Structure Nesting

**Complete cognitive hierarchy:**

```
First layer: My subjective intention (origin)
  ↑
Second layer: My subject-object structure
  ↑  
Third layer: External structure (environmental parameters)
```

**Linkage relationship:**

```
Third layer (external structure) 
    ↓ influences
Second layer (my subject-object relationship) certain dimension
    ↓ changes
First layer (my intention) realization possibility
    ↓ triggers
Strategy adjustment (may reversely influence third layer)
```

### 5.2 Dimension Transmission Model

**How does external structure influence me?**

```
External structure's certain output
    ↓
Influences certain dimension in my subject-object relationship
    ↓
Changes my situation structure
    ↓
Triggers my strategy adjustment
```

**Common transmission paths:**

|External Structure|Influences My Dimension|Transmission Logic|
|---|---|---|
|Supplier-customer relationship|My quality dimension|Customer cost rises → I'm pressured on price|
|Competitor A-B|My action dimension|Opponents battle → my action space|
|Policy-industry|My attitude dimension|Regulation tightens → my willingness|
|Upstream-downstream|My capability dimension|Industry chain reorganizes → my position|
|Platform-merchant|Multiple dimensions|Platform rules → my overall situation|

## 5.3 Complete Case: Phone Accessories Supplier

### Case Story

**My identity:** I run a phone accessories supplier, mainly producing screen protectors.

**My main customer:** Phone Manufacturer B is my largest customer, accounting for 60% of my revenue. We've cooperated for 3 years, relationship fairly stable. Each quarter B gives me orders, I deliver on time, payment term 30 days, basically no problems.

**Peace disrupted:** One day, I see in industry news: **Chip Manufacturer A is conducting difficult supply negotiations with Phone Manufacturer B**.

News reveals:

- A's chip capacity insufficient, technology also has bottlenecks
- B's attitude toward A not good, negotiation atmosphere tense
- But B can't do without A, because can't find alternative chip short-term
- Rumored A may raise prices, or B needs to pay more to get goods

**Why I'm nervous:**

I suddenly realize: **This external structure change will likely affect me!**

- If chip prices rise, B's costs will increase
- B's procurement budget is limited
- Chips are phone's core, B must prioritize chip supply
- So B will likely compress other suppliers' budgets
- **As accessories supplier, I'll likely be pressured on price, even face order cuts**

And worse:

- If B is under pressure, attitude may worsen
- Originally friendly cooperation relationship may become forceful suppression
- I may transform from "partner" to "cost compression target"

**What I need to do:**

I need to:

1. Analyze how Chip Manufacturer A - Phone Manufacturer B external structure will evolve
2. Judge how it will affect my relationship with B (my subject-object structure)
3. Decide what strategy I should take

**This is a typical "external structure affects my situation" scenario.**

---

### Analysis Process

Now let's use external structure analysis method to handle this problem.

#### Step 1: Observe External Structure

**Identify both sides:**

- Chip Manufacturer A (superior)
- Phone Manufacturer B (subordinate)

**Six-dimensional expansion:**

```
Phone Manufacturer B (subordinate):
  Dimension 1 - Action: Actively negotiating +
  Dimension 2 - Quality: Has purchasing power +
  Dimension 3 - Attitude: Very poor negotiation attitude, very tense -

Chip Manufacturer A (superior):
  Dimension 4 - Action: Insufficient capacity -
  Dimension 5 - Quality: Technology has bottlenecks -
  Dimension 6 - Attitude: Still cooperative, willing to talk +
```

**Compression judgment 1 (superior-subordinate grouping):**

- Subordinate (B): ++ - → + (two good one bad, overall acceptable)
- Superior (A): -- + → - (two bad one good, overall not good)
- **Structure type: +- (imbalance structure)**

**Compression judgment 2 (foundation-interaction-target):**

- Foundation layer (B's action + quality): ++ → +
- Interaction layer (both sides' attitude + A's action): -- → -
- Target layer (A's quality + attitude): -+ → +
- **Structure type: +-+ (willing but unable state)**

**Comprehensive judgment:**

- Power comparison: B stronger, A's superior position unstable (imbalance structure)
- Cooperation possibility: Has foundation and willingness, but interaction very poor (willing but unable state)

**Predict how external structure will evolve:**

Short-term (1-3 months):

- A will likely raise prices (or B pays more)
- Because B can't find alternatives short-term, must accept

Mid-term (3-6 months):

- B's cash flow will tighten (chip cost increase)
- B will try to find backup chip suppliers
- B's attitude toward all suppliers will worsen (pressure transmission)

Long-term (6-12 months):

- B may find new chip supplier
- Or B delays new phone release, lowers specs

#### Step 2: Identify Impact Path

**Transmission chain deduction:**

```
External structure change:
Chip cost increase (A raises price or B pays more)
    ↓
First-level transmission:
B's quality dimension worsens (procurement budget consumed by chips)
    ↓
Second-level transmission:
B's attitude dimension worsens (pressure big → fiercer toward all suppliers)
    ↓
Third-level transmission:
My object (B)'s overall structure worsens
    ↓
Fourth-level transmission:
My subject-object structure forced to change
```

**Specifically affects which of my dimensions:**

Direct impact:

- **My object B's quality dimension**: B's budget tightens → may pressure my price
- **My object B's attitude dimension**: B under pressure → attitude toward me worsens

Indirect impact:

- **My action dimension**: Originally could actively promote new products, now dare not
- **My attitude dimension**: Originally fairly assured, now anxious
- **My quality dimension**: If B cuts orders, my capacity becomes burden

#### Step 3: Rejudge My Situation

**Original subject-object structure:**

```
Subject (me): ++ - (capable but resistant state)
  Dimension 1 - Action: Actively getting orders +
  Dimension 2 - Quality: Have capacity, quality also good +
  Dimension 3 - Attitude: Worried about price pressure, somewhat uneasy -

Object (B): - ++ (potential state)
  Dimension 4 - Action: Stable ordering, cooperation smooth +
  Dimension 5 - Quality: Budget already not generous -
  Dimension 6 - Attitude: Cooperation relationship okay, basic trust +
```

This is a fairly acceptable situation:

- I'm somewhat anxious, but overall okay
- B though budget tight, but willing to cooperate
- Both sides relationship stable

**New structure after external shock:**

```
Object (B) changes:
  Dimension 4 - Action: Still needs to order + (can't do without accessories)
  Dimension 5 - Quality: Budget consumed by chips, tighter --
  Dimension 6 - Attitude: Pressure big, attitude toward suppliers worsens -
  New structure: + -- → [Blind action state] (action moving, but no resources no good attitude)

Subject (me) forced to change:
  Dimension 1 - Action: Dare not actively promote (proactive = price pressure) -
  Dimension 2 - Quality: Capacity may be excessive (B may cut orders) -
  Dimension 3 - Attitude: Anxiety deepens --
  New structure: -- - → [Full negative state]
```

**New subject-object superposition:**

```
Me (subject): --- (full negative state) vs B (object): +-- (blind action state)

This is a terrible combination!
```

**Situation judgment:**

- B now is "blind action state": Still moving, but resources tight, attitude poor
- I become "full negative state": Dare not move, resources may be excessive, anxious
- **I'm in extremely passive position**

#### Step 4: Strategy Formulation

**Strategy A: Defensive (short-term)**

1. **Don't take initiative**
    - B now is blind action state, active promotion = price pressure
    - Keep low profile, maintain existing orders
2. **Moderately concede**
    - If B demands price reduction, can make small concession (5-10%)
    - But must clarify "this is because of long-term cooperation, not normal"
3. **Observe and wait**
    - Closely monitor chip negotiation progress
    - Wait for B's pressure release

**Strategy B: Offensive (mid-term)**

1. **Change action dimension**
    
    - From "争订单" to "provide solutions"
    - Help B reduce other costs (like provide one-stop accessory package)
    - Transform self from "cost item" to "value item"
2. **Change quality dimension**
    
    - Develop differentiated products (like more durable film, can reduce B's after-sales cost)
    - Contact B's competitors (diversify risk, don't rely only on B)
3. **Change attitude dimension**
    
    - Prepare to change customers
    - Psychologically no longer treat B as "only customer"

**Strategy C: Intervention (long-term)**

1. **Help B relieve pressure**
    
    - If I have chip supplier resources, introduce to B
    - Unite with other B's suppliers, together give B discounts
    - Transform self from "part of problem" to "person helping B solve problems"
2. **Wait for opportunity**
    
    - Wait for B's pressure to pass (find new chip supplier/funding relief)
    - Then discuss long-term cooperation, price increases etc.

#### Step 5: Dynamic Monitoring

**Set monitoring nodes:**

|Time|Key Event|Observation Indicator|Expected|What if Doesn't Meet Expectations|
|---|---|---|---|---|
|T+1 week|Chip negotiation result announced|Whether B raises price/finds new supplier|A raises price, B accepts|If B finds new supplier, pressure small, I don't need to be too nervous|
|T+1 month|B's order volume|Whether orders decrease|Decrease 10-20%|If decrease exceeds 30%, activate Strategy B (contact other customers)|
|T+2 months|B's payment speed|Whether payment term extends|May extend to 45 days|If exceeds 60 days, indicates B's cash flow very poor, consider Strategy C|
|T+3 months|B's new phone release|Whether delayed/downgraded|May delay|If cancelled, I need to immediately find new customers|
|T+6 months|B's financial report|Revenue and profit|Decline|Evaluate whether to long-term reduce dependence on B|

## Section 6: Honestly Face Limitations and Boundaries

### 6.1 Discussion of Four Limitations

#### Limitation 1: Compression Loses Details

**Reality:**

- This isn't a defect, but a tradeoff
- Quick judgment must sacrifice details for speed
- The brain actually operates this way

**Response:**

- Use compression for quick scanning
- Decompress when decisions involved
- Clearly mark "this is rough judgment"

#### Limitation 2: Superior-Subordinate Judgments May Differ

**Reality:**

- Different judgments stem from different intentions, insufficient information, different focus points
- Wrong judgment → wrong result → correction → learning
- **This is the real cognitive process**

**Response:**

- When judging superior-subordinate, mark "under specific intention, I think X is superior"
- Don't claim "naturally so"
- Allow different people different judgments

#### Limitation 3: Impact Path Identification Requires Experience

**Reality:**

- StructLang provides framework (which dimensions may be affected)
- Specific content needs domain experience filling

**Response:**

- Structure analysis + domain knowledge, both indispensable
- In familiar domains, impact paths clear
- In unfamiliar domains, need trial and error verification

#### Limitation 4: Complexity of Multiple External Structures

**Reality:**

- Humans indeed get confused facing multiple external structures
- Can break into multiple independent structures for separate analysis
- Or compress into one point then decompress

**Response:**

- Identify main contradiction (most critical external structure)
- Simplify secondary structures
- Acknowledge boundaries of processing capability

### 6.2 Theory's Boundary Problem

**Open question:** Is there any human cognitive process that cannot be described by "compression/decompression + point-line-surface-volume + intention-driven"?

**Possible candidates:**

- Pure emotional impulse (no compression/decompression, direct reaction)
- Epiphany-style creation (not point-to-line expansion, but leap)
- Bodily skills (doesn't go through conscious structure judgment)

**Honest attitude:**

- Don't claim "any cognition can be described with StructLang"
- Stay open, seek boundaries
- At boundaries may have new discoveries

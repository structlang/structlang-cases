你走进面馆，点了碗面。

面端上来，你尝第一口——

"嗯，还行。"

这个"还行"是怎么来的？

不是你把这碗面和黄焖鸡、麻辣烫拿来比较。而是你的大脑在那一瞬间，把这碗面放在了一条**隐形的轴**上。

这条轴的一端是"难吃"，另一端是"好吃"，中间是"无所谓"。

你给这碗面定了位：稍微偏向"好吃"那一端，大概+0.6的位置。

**这条轴，就是线结构。**

但在讲线结构之前，需要先说明：判断不是固定的。同样一碗面，你对它的评价可能会改变。这种改变有三种完全不同的性质，我们稍后会详细讨论。

现在，先看线结构的基本概念。

---

## 线结构是什么

线结构就是一条由意图决定的**判断轴**。

它有三个要素：

**1. 原点** - 判断的起点，由意图决定

- "这碗面值不值得吃"的原点，是"能不能接受"

**2. 正方向** - 意图期望的方向

- 在"吃面"这个意图下，正方向是"好吃"

**3. 判断落点** - 对象在轴上的位置

- 这碗面被定位在+0.6（还不错）

用符号表示：

```
不好吃(-) ←—— 0 ——→ 好吃(+)
              ↑
            +0.6
```

线结构不是发明出来的方法，而是你大脑一直在用的方式。每次你说"好""不好""还行""不太行"，都是在用线结构。

---

## 意图决定了轴的方向

关键洞察：**同一个对象，在不同意图下，在轴上的位置完全不同。**

还是那碗面。

**意图1：填饱肚子**

```
不饱(-) ←—— 0 ——→ 很饱(+)
              ↑
            +0.8
```

这碗面分量足，在"是否能吃饱"这个意图下，被定位在+0.8。

**意图2：享受美食**

```
难吃(-) ←—— 0 ——→ 美味(+)
              ↑
            +0.3
```

但味道一般，在"是否美味"这个意图下，只有+0.3。

**意图3：健康饮食**

```
不健康(-) ←—— 0 ——→ 健康(+)
           ↑
         -0.4
```

太油腻，在"是否健康"这个意图下，变成了-0.4。

**同一碗面，三个意图，三个位置。**

这不是"你的看法变了"，而是**判断轴本身变了**。换了意图，就换了轴，整个判断系统就重建了。

---

## 正负是相对的

再看一个例子。

西瓜摊上，你切开一个瓜尝：

"甜！+0.9"

旁边的糖尿病人也尝了一口：

"太甜了。-0.8"

同一个"甜"，为什么判断相反？

因为意图不同：

**你的轴**：

```
不甜(-) ←—— 0 ——→ 甜(+)
               ↑
             +0.9
```

**他的轴**：

```
甜(-) ←—— 0 ——→ 不甜(+)
      ↑
    -0.8
```

正负方向完全颠倒了。

**这就是线结构的本质：没有"客观的好坏"，只有"在某个意图下的正负"。**

---

## 线结构无处不在

你每天都在用线结构，只是没有意识到：

**早上选衣服**

```
意图：今天要见客户
轴：随便(-) ←—— 正式(+)
这件衬衫：+0.7
```

**开会听发言**

```
意图：这个提案可行吗
轴：不可行(-) ←—— 可行(+)
他的方案：-0.3
```

**晚上刷手机**

```
意图：找点有意思的
轴：无聊(-) ←—— 有趣(+)
这条视频：+0.5
```

每一个判断，都是一个线结构。

---

## 判断的三种改变

线结构不是固定的。"改变"分三种性质完全不同的类型。

### 类型一：在同一条轴上移动

你吃着面，觉得还行（+0.6）。

翻到底下，发现藏着一大块牛肉。

"哦！还不错。"

判断从+0.6跳到+0.8。

**发生了什么？**

- 还是在"好不好吃"这条轴上
- 只是位置移动了：新信息让你给它打了更高分

**这是第一种改变：对象在轴上的位置移动了。**

---

### 类型二：正方向反转

你点的是麻辣面，端上来尝第一口：

"辣！够味！+0.8"

你很满意，因为你要的就是辣。

**此时的轴：**

```
不够辣(-) ←—— 0 ——→ 够辣(+)
                 ↑
                +0.8
```

吃到一半，辣得胃开始不舒服，嘴唇发麻。

现在你再评估这个"辣"：

"太辣了！-0.8"

**此时的轴：**

```
太辣(-) ←—— 0 ——→ 不那么辣(+)
	    ↑
      -0.8
```

**发生了什么？**

- 还是在评估"辣度"这个维度
- 但正方向反了：原来"越辣越好"，现在"越不辣越好"
- 面的辣度本身没变，变的是你的承受状态

**这是第二种改变：轴的正方向反转了。**

再一个例子：

冬天，你点了一碗热汤面：

"够烫！舒服！+0.9"

```
不够热(-) ←—— 0 ——→ 够热(+)
                 ↑
                +0.9
```

夏天，同样一碗热汤面端上来：

"这么烫！-0.7"

```
太烫(-) ←—— 0 ——→ 凉爽(+)
        ↑
      -0.7
```

还是"温度"这个维度，但季节变了，正方向就反了。

---

### 类型三：换了一条轴

你吃着面，正吃得香。

突然咬到一根头发。

"卧槽！"

**发生了什么？**

- 不是那碗面从"好吃"变成"不好吃"
- 而是你根本不在"好不好吃"这条轴上了
- 你切换到了"干不干净/安不安全"这条新轴

```
旧轴：难吃(-) ←—— 0 ——→ 好吃(+)

新轴：不卫生(-) ←—— 0 ——→ 卫生(+)
         ↑
       -0.9
```

**这是第三种改变：整条轴都变了。**

---

## 三种改变的本质区别

|改变类型|维度是否改变|正方向是否改变|例子|
|---|---|---|---|
|类型一：位置移动|否|否|发现藏着肉：+0.6→+0.8|
|类型二：方向反转|否|**是**|从"越辣越好"变成"越不辣越好"|
|类型三：换轴|**是**|**是**|从"口味轴"切换到"卫生轴"|

**为什么要区分这三种？**

因为应对方式完全不同：

- **类型一**：补充信息就能解决（"其实里面有肉"）
- **类型二**：需要调整状态或等待时机（"等不那么辣了再吃""换个季节再来"）
- **类型三**：需要回应新意图（"我保证卫生"）

**现实中最容易搞混的是类型二和类型三：**

有人说"我以前喜欢吃辣，现在不喜欢了"——这是类型二（辣的正方向反了）

有人说"我以前关注口味，现在关注健康"——这是类型三（从口味轴换到健康轴）

---

## 只有一条轴还不够

现在问题来了。

你面前有两个工作机会：

**工作A**

- 钱多：+0.9
- 但通勤远：-0.7

**工作B**

- 钱少：+0.3
- 但通勤近：+0.8

怎么选？

单独一条"钱多钱少"的轴，A更好。 单独一条"通勤远近"的轴，B更好。

**两条轴给出了矛盾的结论。**

你需要把两条轴放在一起看。这就引出了下一个层次：面结构。

## Opening: Stability Is Temporary

**Introductory Case: Three Marriages, Three Windows**

```
Marriage A: Met → Married → Divorced, 3 years
Marriage B: Met → Married → Adjustment → Stable → Crisis → Divorced, 15 years  
Marriage C: Met → Married → Lifelong, 50 years

Why such vastly different stability periods?
What determines how long a structure can last?
```

**Core Insight: All stability exists within time windows.**

- There is no eternally stable structure
- Only structures that are "stable for a certain period of time"
- The question isn't "is it stable" but "how long is it stable"

## Section 1: Definition of Time Window

### 1.1 What Is a Time Window

**Definition: Under a certain intention, the time period during which a structure remains relatively stable.**

Symbolic representation:

```
[T0-Tn]: Structure description

T0 = Window start (after last leap/when intention anchored)
Tn = Window end (before next leap/before intention switch)
delta = Tn - T0 = Window length
```

### 1.2 Three Elements of a Window

**Element 1: Boundaries**

- Start point: Structure formation or after last leap
- End point: Leap occurs or intention switches

**Element 2: Content**

- Within window: Relative stability of same structure
- Allows minor fluctuations, but no leaps

**Element 3: Length**

- From seconds to generations, spanning enormous range
- Length determined by stability mechanisms

### 1.3 Meaning of "Relative Stability"

**Not absolute stillness:**

```
[T0-T5]: Employee (+0.7, +0.8, -0.5)

Fluctuations may occur within window:
T1: (+0.7, +0.8, -0.5)
T2: (+0.75, +0.8, -0.5)  ← Action slightly improved
T3: (+0.7, +0.85, -0.5)  ← Quality slightly enhanced
T4: (+0.7, +0.8, -0.6)   ← Attitude slightly worsened

But overall judgment unchanged: (+ + -) pattern stable
```

**When does it count as a leap:**

- Sign flip in a dimension: - becomes +, or + becomes -
- Overall pattern changes: (+ + -) becomes (+ - -)
- Subject-object relationship reorganizes

## Section 2: Five Sources of Stability

### 2.1 Source 1: Weight Inertia

**High-weight causal impressions maintain stability**

```
Case: Established impression of veteran employee

"He's just slow" (weight 0.9)
→ Even if he's fast once, you think "coincidence"
→ Your judgment of him remains stable within window

Why stable?
- High-weight causal impressions resist rewriting
- Requires many counterexamples to shake
- All behavior during this period "assimilated" by this impression
```

**Relationship between weight and window length:**

```
Higher weight → Longer window
Weight 0.9 impression > Weight 0.6 impression

Because:
- High weight requires stronger counterexamples to rewrite
- More information automatically incorporated into existing framework
- Less likely to trigger re-evaluation
```

### 2.2 Source 2: Continuation of External Conditions

**Environment unchanged, structure stable**

```
Case: Workplace relationship stability

[Joining-Year 1]: 
You(+,+,+) × Boss(+,+,-)
Boss is capable and willing but cold in attitude

Window stable because:
- Company system unchanged
- Business model unchanged
- Your position unchanged
- Boss's style unchanged

What would break it?
- Company restructuring (external conditions change)
- Your promotion (relationship position changes)
- Boss replacement (subject changes)
```

**Types of external conditions:**

|Condition Type|Example|Consequence of Change|
|---|---|---|
|Institutional environment|Company rules, legal framework|Rule change → Behavior change|
|Resource constraints|Budget, time, manpower|Constraint release → Capability unleashed|
|Social norms|Industry conventions, cultural expectations|Norm loosening → Behavior permission|
|Physical conditions|Geography, climate, tech level|Condition change → Possibility change|
|Information environment|What you know, don't know|New info → Cognitive restructuring|

### 2.3 Source 3: Intention Persistence

**Under same intention, origin unchanged, structure stable**

```
Case: Persistent debt collection

[T0-T6]: <Recover scammed money>
This intention persists for a week

Stable within window:
- Origin anchored: Legal compliance
- Judgment of merchant: (-,+,-)
- Action direction: Rights protection

If intention switches:
T3: <Forget it, not worth wasting time> ← New intention
→ Origin leap: Time cost
→ Judgment of merchant may change: Don't care anymore
→ Window ends
```

**Intention persistence depends on:**

- Weight (importance) of intention
- Whether covered by new intention
- Whether goal achieved or confirmed unreachable

### 2.4 Source 4: Compression Solidification

**Compression method unchallenged, judgment stable**

```
Case: Project evaluation

[Research phase]: Project [+0.8, -0.6] (benefit × risk)

This compression stable because:
- Benefit dimension: Financial model clear
- Risk dimension: Using industry standard method
- Both dimensions unchallenged

What would break it?
- New evaluation dimension appears: "Social impact"
- Original dimension challenged: "Financial model wrong"
- Intention changes: "Not just about money anymore"
→ Decompression reconstruction → Window ends
```

### 2.5 Source 5: Social Consensus Support

**Multi-agent overlap stable, individual judgment stable**

```
Case: Evaluation of someone

Your judgment of him: (+,+,-)
Colleagues also see it this way: (+,+,-)
Boss also sees it this way: (+,+,-)

Consensus stable → Your judgment more stable

Why?
- Social validation reinforces your causal impression
- Occasional counterexamples assimilated by group
- "Everyone says so" increases weight
```

**Consensus is stability amplifier:**

- Individual judgment: Easily influenced by single experience
- Small group consensus: Enhanced interference resistance
- Large-scale consensus: Extremely stable (like scientific laws)

### 2.6 Synergy of Five Sources

**Stability = f(Weight, External conditions, Intention persistence, Compression solidification, Social consensus)**

```
Most stable structure:
- High-weight causal impression ✓
- External conditions stable ✓
- Long-term intention persistence ✓
- Compression unchallenged ✓
- Broad social consensus ✓
→ Extremely long window (like scientific laws)

Most unstable structure:
- Low-weight impression ✗
- External violent fluctuations ✗
- Intention switches constantly ✗
- Compression frequently challenged ✗
- No social consensus ✗
→ Extremely short window (like emotional states)
```

## Section 3: Window Length Spectrum

### 3.1 Extremely Short Windows (Seconds-Minutes)

**Characteristic: Change upon trigger**

```
Case: Seeing red light and braking

[T0: See red light]
Intention: <Stop>
Judgment: Ahead (red)[traffic light]
Action: Press brake

[T1: Green light after 5 seconds]
Intention switches: <Proceed>
Judgment: Ahead (green)[traffic light]
Action: Accelerate

Window length: 5 seconds
```

**Scenarios for extremely short windows:**

- Physiological reactions (pain → avoidance)
- Conditioned reflexes (doorbell → open door)
- Immediate emotions (insulted → angry)
- Procedural tasks (red light → green light)

### 3.2 Short Windows (Hours-Days)

**Characteristic: Daily fluctuations**

```
Case: Daily work state

[Morning]: Energy (+0.8)[state]
[Afternoon]: Energy (+0.5)[state]  
[Evening]: Energy (+0.2)[state]

Window length: Circadian rhythm within a day
```

**Scenarios for short windows:**

- Emotional ups and downs (happy → calm → irritated)
- Daily tasks (morning meeting → lunch → leaving work)
- Temporary plans (things to do today)

### 3.3 Medium Windows (Weeks-Months)

**Characteristic: Project cycles, relationship phases**

```
Case: Fake dog return

[T0-T6]: One-week rights protection process
Intention stable within window: <Recover scammed money>
Window end marker: Refund success
```

**Scenarios for medium windows:**

- Project cycles (initiation → delivery)
- Relationship phases (honeymoon period, adjustment period)
- Habit formation (21-day challenge)
- Quarterly goals

### 3.4 Long Windows (Years)

**Characteristic: Life stages, career states**

```
Case: Career stability period

[Joining-Year 5]: 
Me(+,+,+) × Company(+,+,-)
Technical improvement, but promotion blocked

Window length: 5 years
Window stability factors:
- Industry skill accumulation (high weight)
- Company system stable (external conditions)
- Intention persistence: Improve professional capability
- Social consensus: This is a good company
```

**Scenarios for long windows:**

- Career stages
- Marriage stability period
- Long-term rental/mortgage payment period
- Chronic disease treatment cycle

### 3.5 Extremely Long Windows (Generations-Centuries)

**Characteristic: Cultural heritage, scientific paradigms**

```
Case: Newtonian mechanics

[1687-1905]: 200+ year stability period
All physicists consensus: Newtonian mechanics = truth

Why extremely long?
- Extremely high weight: Countless validations
- External conditions stable: Macroscopic low-speed world unchanged
- Intention persistence: Explaining physical phenomena
- Compression solidified: Textbooks passed down generations
- Social consensus: Global scientists agree

Window ends:
1905 relativity, 1926 quantum mechanics
→ Boundary conditions exposed
→ New paradigm established
```

**Scenarios for extremely long windows:**

- Scientific laws (within applicable scope)
- Cultural traditions (values, rituals)
- Language structures (grammar evolves extremely slowly)
- Institutional frameworks (constitutional level)

### 3.6 Core Factors Determining Length

|Factor|Short Window|Long Window|
|---|---|---|
|**Weight**|Low-weight causal impression|High-weight causal impression|
|**External conditions**|Rapid change|Long-term stability|
|**Intention**|Temporary, easily switched|Persistent, deeply rooted|
|**Compression**|Easily challenged|Solidified, hard to shake|
|**Social consensus**|Individual/small group|Large-scale/cross-generational|
|**Tension accumulation speed**|Fast|Slow|
|**Counterexamples needed for rewriting**|Few (1-2 enough)|Many (requires sustained counterexamples)|

## Section 4: Identifying Window Boundaries

### 4.1 Signs of Window Start

**Signal 1: Leap just occurred**

```
Employee (- + +) |Complete key task| => (+ + +)
→ New window begins
→ Your judgment of them enters new stability period
```

**Signal 2: New intention anchored**

```
Before: <Routine work>
Now: <Important project> ← New intention
→ New window begins
→ Re-evaluate everything under new intention
```

**Signal 3: New information triggers reconstruction**

```
[T0-T2]: Think project is good
T3: Discover financial data fraud
→ Decompression reconstruction
→ New window: Think project has problems
```

### 4.2 Signs Window About to End (Critical)

**Signal 1: Tension accumulated to critical point**

```
Manifestations:
- Small conflicts occur frequently
- "Can't stand it anymore" feeling
- Original coping methods fail
- Emotional reactions intensify

Case: Workplace relationship
[T0-11 months]: Tolerate boss's style (+ + -)
[12th month]: 
- Feel oppressed every meeting
- Often complain after work
- Start looking at job postings
- "Want to quit over small things"

→ Tension approaching threshold
→ Window about to end
```

**Signal 2: Harbingers of dramatic external change**

```
Manifestations:
- Policy wind direction changes
- New market players appear
- Technology breakthrough rumors
- Organizational restructuring announcements

Case: Industry stability period
[T0-3 years]: Traditional retail stable
Early 2010s:
- Internet penetration rate surges
- Mobile payment emerges
- E-commerce platforms rise

→ Massive external change imminent
→ Window about to close
```

**Signal 3: Intention starts wavering**

```
Manifestations:
- "Why am I persisting with this?"
- Start considering other options
- Enthusiasm for original goal decreases
- New intention budding

Case: Weight loss plan
[T0-2 weeks]: <Lose weight> intention stable
Week 3:
- "Maybe not that fat"
- "Eating occasionally is fine"
- "Health matters more than weight" ← New intention budding

→ Intention about to switch
→ Window about to end
```

**Signal 4: Compression frequently challenged**

```
Manifestations:
- Original judgment framework fails
- New dimensional information floods in
- "Old methods can't explain it anymore"

Case: Judgment of someone
[T0-5]: Think he's (+ + -)
Recently:
- Discover he privately cares for newcomers (new info)
- His "coldness" might be protective mechanism (new perspective)
- "Did I misunderstand him?" (Compression challenged)

→ Decompression reconstruction imminent
→ Window about to end
```

**Signal 5: Social consensus loosening**

```
Manifestations:
- "Everyone's opinion changed"
- Authoritative views questioned
- New consensus forming

Case: Evaluation of a company
[T0-2 years]: Industry consensus: XX company very stable
Recently:
- Negative news frequent
- Employee turnover rate rises
- Competitor reputation overtakes

→ Consensus disintegrating
→ Window about to end
```

### 4.3 Cost of Missing Boundaries

**Cost 1: Passive leap**

```
Didn't notice signals → Sudden collapse
"How did it suddenly become like this?"

Reality: Tension accumulated long ago, you just didn't see it
```

**Cost 2: Missing optimal timing**

```
Should have quit at T5 (proactive)
Dragged to T8 and got laid off (passive)

Difference:
- Proactive: Have choice, prepared
- Passive: Rushed response, few options
```

**Cost 3: Over-investment**

```
Window about to end, still increasing investment
"Already invested so much, can't give up"
→ Sunk cost trap
→ Losses amplified
```

## Section 5: Dynamics Within Window

### 5.1 Not Completely Static

**Changes allowed within window:**

```
[T0-T5]: Employee (+ + -)

T0: (+0.7, +0.8, -0.5)
T1: (+0.75, +0.8, -0.5)  ← Action improved
T2: (+0.75, +0.85, -0.5) ← Quality enhanced
T3: (+0.7, +0.85, -0.6)  ← Attitude worsened
T4: (+0.75, +0.8, -0.55) ← Minor fluctuation
T5: (+0.7, +0.8, -0.5)   ← Return

Overall judgment: (+ + -) unchanged
Window: Stable
```

### 5.2 Minor Fluctuation vs Structural Leap

**Judgment criteria:**

|Dimension|Minor Fluctuation|Structural Leap|
|---|---|---|
|Sign|Unchanged (+ remains +, - remains -)|Flipped (+ becomes -, or - becomes +)|
|Magnitude|Within ±0.3 range|Exceeds ±0.5|
|Pattern|(+ + -) type unchanged|Changes to (+ - -) etc.|
|Subjective feel|"Some change, but still basically same"|"Completely different"|
|Coping method|Original strategy still effective|Need re-evaluation|

**Case comparison:**

```
Minor fluctuation:
[Monday]: Boss(+,+,-0.5) "Bad mood today"
[Tuesday]: Boss(+,+,-0.3) "Mood better"
→ Judgment: (+ + -) unchanged
→ Window: Continues

Structural leap:
[T0-T5]: Boss(+,+,-)
[T6]: Boss suddenly shows active concern, continues one week
[T7-T10]: Boss(+,+,+)
→ Judgment: Attitude flipped from negative to positive
→ Window: Ends, new window begins
```

### 5.3 Role of Trends

**Trend: Directional change within window**

```
Symbols:
(+ + -)^  Upward trend (some dimension improving)
(+ + -)v  Downward trend (some dimension deteriorating)
(+ + -)->  Sideways (temporarily stable)
```

**Relationship between trend and window:**

```
Situation 1: Trend not accumulated to threshold
[T0-T5]: (+ + -)^
→ Though trending, window still stable
→ Pattern hasn't leaped

Situation 2: Trend accumulation triggers leap
[T0-T5]: (+ + -)^
[T6]: Accumulation complete => (+ + +)
→ Trend converts to leap
→ Window ends
```

**Practical implications:**

- Note trend direction
- Assess accumulation speed
- Predict leap timing

### 5.4 Weight Micro-adjustments

**Weight also changes within window:**

```
[T0]: "He can't do it" (weight 0.7)
[T1]: He completed a task (small success)
     → "He can't do it" (weight 0.65) ← Slightly decreased
[T2]: Another small success
     → "He can't do it" (weight 0.6)
[T3]: Another
     → "He can't do it" (weight 0.55)
...
[T10]: Weight drops to 0.4
     → Triggers re-evaluation
     → "Maybe he can" (new causal impression)
     → Leap
```

**Micro-adjustment vs Leap:**

- Micro-adjustment: Weight within ±0.1 range
- Leap: Weight crosses certain threshold (usually 0.5)

### 5.5 When Fluctuation Becomes Leap

**Critical conditions:**

```
1. Accumulated amount reaches threshold
   N small changes → Qualitative change

2. Touches core assumption
   Challenges bottommost causal impression

3. Intention suddenly switches
   Origin changes → Complete re-evaluation

4. External forcible intervention
   Sudden event → Forced change

5. Social consensus flips
   "Everyone changed" → You change too
```

## Section 6: Nested Multiple Windows

### 6.1 Same Object Under Different Intentions

**Different windows:**

```
Object: Employee Xiao Li

[Work intention]: (+ + -) @[Joining-present]
  Strong action, good quality, poor attitude
  Window: 2 years

[Personal relationship intention]: (- - +) @[Met-present]  
  Not proactive, not deep, but sincere
  Window: 2 years

Same person, two windows, two judgments
```

**Why different:**

- Different intentions → Different origins
- Different dimensions of focus
- Different causal impressions invoked

### 6.2 Short Windows Nested in Long Windows

**Hierarchical structure:**

```
Long window [Joining-leaving]: 5 years
  ├─ Medium window [Rookie period]: 1 year
  │   ├─ Short window [Training week]: 2 weeks
  │   │   ├─ Extremely short window [Certain meeting]: 2 hours
  │   │   └─ ...
  │   └─ ...
  ├─ Medium window [Growth period]: 2 years
  ├─ Medium window [Stable period]: 1.5 years
  └─ Medium window [Leaving period]: 0.5 year
```

**Short window leap vs Long window stability:**

```
Case:
Long window judgment: Me(+,+,+) × Boss(+,+,-) @[Joining-2 years]

Within short window:
- Once criticized: Boss(+,+,--) @[That week]
- Once praised: Boss(+,+,0) @[Another week]
- Daily interaction: Boss(+,+,-) @[Normally]

Fluctuations within short window don't change long window judgment
```

**When short window affects long window:**

- Short window leaps occur frequently
- Cumulative effect breaks threshold
- "This isn't random, it's a trend"
- Long window judgment forced to adjust

### 6.3 Cross-Window Influences

**Case: Work affecting family**

```
Work window:
[T0-6 months]: High-pressure project
Intention: <Complete project>
Judgment: Me(+,-,-) Exhausted, anxious

Family window:
[Same period]: 
Intention: <Maintain family>
Judgment: Me(+,-,-) Present but mind absent

Work window state → Transmits to → Family window
Can isolate short-term, long-term will mutually affect
```

**Mechanisms of mutual influence:**

- Resource competition (time, energy)
- Emotional transmission (negative overflow from one window)
- Intention conflict (two intentions incompatible)
- Identity confusion (role-switching failure)

## Section 7: Practical Applications

### 7.1 Choosing Correct Time Scale

**Common error: Scale mismatch**

```
Error 1: Using short window to judge long-term problem
"He performed poorly today" → "He's not good at all"
Should: Observe pattern over longer window

Error 2: Using long window to respond to short-term crisis
"We've always done it this way" → Still use old methods facing sudden situation
Should: Recognize short window specificity

Error 3: Confusing judgments from different windows
"Last week I thought he's good, this week not good, which should I believe?"
Should: Understand these are snapshots from different windows
```

**Matching principles:**

|Problem Type|Time Scale to Use|Example|
|---|---|---|
|Strategic decisions|Long window (years)|Career direction, marriage, buying house|
|Project management|Medium window (weeks-months)|Product development, event preparation|
|Daily response|Short window (days)|What to do today, how to reply email|
|Crisis handling|Extremely short window (hours)|Emergencies, urgent decisions|
|Relationship judgment|Long window + short window observation|Continuous observation, not influenced by single event|
|Market forecasting|Medium-long window, beware short-term noise|Not misled by daily fluctuations|
|Self-assessment|Long window for growth, short window for state|Long-term progress vs today's state|

### 7.2 Using Stability Period for Planning

**Window stability period is action window:**

```
Identify stability period:
- External conditions temporarily unchanged
- Intention clear and stable
- Resources relatively sufficient
- No urgent crisis

What to do during stability period:
✓ Advance long-term plans
✓ Accumulate capabilities and resources
✓ Build solid relationships
✓ Do things requiring sustained investment

Avoid during stability period:
✗ Not vigilant, thinking it'll stay stable forever
✗ Not prepared, ignoring signals of window closure
```

**Case: Career stability period**

```
[Joining-Year 3]: Stability period
- Work mastered, not too busy
- Good relationship with boss
- Won't be laid off short-term

This is window period, should:
✓ Deepen professional skills
✓ Build industry network
✓ Try new projects
✓ Prepare for next stage (promotion or job hop)

Should not:
✗ "Pretty good, just stay like this" (comfort zone)
✗ Not preparing for window end
```

### 7.3 Making Decisions at Window Boundaries

**Boundaries are critical moments:**

```
When window about to end:
- Old structure about to collapse
- New structure not yet formed
- Highest malleability
- Greatest decision impact

At boundary should:
✓ Identify signals (Section 4)
✓ Assess direction (where will it leap)
✓ Proactively intervene (push toward favorable direction)
✓ Prepare contingency (in case leaps unfavorably)
```

**Case: Proactivity on eve of leap**

```
Situation:
[T0-11 months]: You(+,+,+) × Boss(+,+,-)
Tension accumulated, about to leap

Three possibilities:
1. Leap to (+,+,+): Boss attitude turns positive, stay
2. Leap to (+,+,--): Completely deteriorates, forced to leave
3. Proactive leap: You leave first, new job

Month 12:
If passively wait → Possible result 1 or 2, random
If proactively act → Create result 3, controllable

Proactive action:
- Submit résumés
- Find next position
- Choose timing to resign
→ Seize initiative
```

### 7.4 Proactively Creating/Extending/Shortening Windows

**Creating new window:**

```
Proactively trigger leap, enter new window

Case:
Dissatisfied with status quo → Quit to start business
→ Old window (employment) ends
→ New window (entrepreneurship) begins
```

**Extending window:**

```
Maintain stability, delay leap

Methods:
- Dissolve tension (small improvements avoid eruption)
- Stabilize external conditions (reduce variables)
- Maintain intention (don't easily switch goals)
- Consolidate consensus (strengthen support)

Case:
Want to retain employee → Extend their stability period
- Small raise (dissolve quit impulse)
- Improve relationship (maintain intention)
- Provide development (stabilize external conditions)
→ Delay their leap moment
```

**Shortening window:**

```
Accelerate leap, quick switch

Methods:
- Create tension (intensify contradictions)
- Change external conditions (create shock)
- Switch intention (change perspective)
- Break consensus (introduce disagreement)

Case:
Want them to leave voluntarily:
- Marginalize them (create tension)
- Cut resources (change conditions)
- Hint poor prospects (affect intention)
→ Accelerate their resignation leap
```

### 7.5 Avoiding Common Errors

**Error 1: Carving boat for sword**

```
"It worked before, should work now"
Problem: Window changed, old method fails
Should: Recognize window change, adjust strategy
```

**Error 2: Giving up too early**

```
"No immediate effect, doesn't work"
Problem: Judging long-term problem in short window
Should: Give enough time to observe long window effect
```

**Error 3: Mistaking endpoint for eternity**

```
"Finally stable, can relax"
Problem: All stability is temporary
Should: Prepare for next stage during stability period
```

**Error 4: Ignoring signals**

```
"Should be fine"
Problem: Ignoring signals window about to end
Should: Stay sensitive, prepare in advance
```

New window
- Intention: <Rights protection through regulation>

Window end marker: Key information

New window, tension accumulating

**Insights:**

- 7 windows, each different length
- Short window (T3-T4) most critical
- Actions at boundary moments determine direction

## Summary: Value of Time Window Thinking

**Core insights:**

1. **All stability is temporary**
    
    - No eternal structures exist
    - Only stability within time windows exists
2. **Windows have boundaries**
    
    - Identify start and end signals
    - Boundaries are critical decision moments
3. **Window length is predictable**
    
    - Based on five stability sources
    - Assess remaining time
4. **Windows are operable**
    
    - Can create, extend, shorten
    - Proactively influence rather than passively accept
5. **Choose correct time scale**
    
    - Match problem and window length
    - Don't make long-term judgments in short windows
    - Don't respond to short-term crises with long windows

**Practical value:**

- No longer surprised by "sudden" (because see signals in advance)
- No longer miss timing (because know where boundaries are)
- No longer give up too early or persist excessively (because know window length)
- No longer respond passively (because can proactively operate windows)

**Time window thinking lets you:**

- Think about problems at appropriate time scale
- Accumulate during stability, decide at boundaries
- See rhythm and patterns of change
- Transform from passive acceptance to proactive grasp

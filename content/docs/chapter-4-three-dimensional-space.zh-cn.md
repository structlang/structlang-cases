你要录用一个人。

面试时，这个候选人表现不错：

**能力维度：**

```
能力差(-) ←—— 0 ——→ 能力强(+)
                      ↑
                    +0.8
```

能力很强，技术过硬。

**态度维度：**

```
态度差(-) ←—— 0 ——→ 态度好(+)
                      ↑
                    +0.9
```

态度也很好，表现出强烈的工作意愿。

在"能力×态度"的面结构上，他是(++),看起来很理想。

你录用了他。

---

## 三个月后的问题

三个月后，你发现不对劲。

这个人：

- 会议上侃侃而谈（态度+）
- 技术储备确实充足（能力+）
- 但任务推进为零（行动-）

他每天准时上班，参加所有会议，积极发言，但就是不做事。或者说，**不真正推进工作**。

你回头看面试时的判断：

```
     能力强(+)
        ↑
        |
        |  (++）
        |  他在这里
————————+————————→ 态度好(+)
        |
```

没错啊，能力+态度+，确实是(++)。

**但你漏掉了第三个维度：行动。**

---

## 第三个维度

如果加上"行动"这个维度：

```
意图：评估这个人是否适合录用

三个维度：
- 行动：是否真正在推进工作
- 能力：是否具备完成工作的能力  
- 态度：是否有工作的意愿
```

现在，你重新评估这个人：

- 行动：-（不推进工作）
- 能力：+（技术过硬）
- 态度：+（表现积极）

**他的真实状态是(-,+,+)**，不是(+,+,+)。

这就是**三维结构**。

---

## 三条轴的交叉

把三条轴放在一起，形成一个立体空间，与点结构、线结构和面结构相对应，我们也可以称之为“**体结构**”：

```
        行动(+)
          ↑
          |
          |
	   O  +————→ 能力(+)
         /
        /
       ↙
   态度(+)
```

三条轴从同一个原点O出发，向三个方向延伸。

**原点O是什么？**

还是同一个意图："评估这个人是否适合录用"。

三条轴的原点**必须重合**，这意味着：

- 三个维度都在服务于同一个意图
- 不是三次独立的判断
- 而是一次立体的组合判断

如果第三条轴的原点不在这里（比如你突然考虑"他长得帅不帅"），这条轴就不能和前两条交叉成有意义的三维结构。

---

## 八个区域

三条轴交叉，会形成**八个区域**。

为什么是八个？

因为每个维度有两种状态（+或-），三个维度的组合就是：2×2×2 = 8。

**八种组合：**

1. **(+,+,+)** - 行动+，能力+，态度+
2. **(+,+,-)** - 行动+，能力+，态度-
3. **(+,-,+)** - 行动+，能力-，态度+
4. **(+,-,-)** - 行动+，能力-，态度-
5. **(-,+,+)** - 行动-，能力+，态度+ ← 那个候选人在这里
6. **(-,+,-)** - 行动-，能力+，态度-
7. **(-,-,+)** - 行动-，能力-，态度+
8. **(-,-,-)** - 行动-，能力-，态度-

那个候选人落在第5个区域：**(-,+,+)**。

有能力，有意愿，但不行动。

---

## 为什么是这三个维度？

你可能会问：为什么选"行动、能力、态度"这三个维度？

因为在"评估一个人是否适合录用"这个意图下，这三个维度最关键：

- **能力**：他能不能做到
- **态度**：他想不想做
- **行动**：他有没有在做

三个维度回答了三个不同的问题。

但注意：**维度不限于这三个。**

如果你的意图是"评估一个投资项目"，三个维度可能是：

- 收益：赚不赚钱
- 风险：安不安全
- 时机：现在做合不合适

如果你的意图是"选择一家餐厅"，三个维度可能是：

- 口味：好不好吃
- 价格：贵不贵
- 距离：远不远

**三维结构的关键不是具体用哪三个维度，而是：在同一意图下，同时考虑三个相关的判断维度。维度之间不能完全重叠，否则结构会坍塌；但也必须相关，否则它们无法共同服务于同一意图。**

在本书后续章节中，我们会大量使用"行动(A)、素质/能力(Q)、态度(T)"这三个维度。

为什么选这三个？

因为它们在**评估主体行为**时具有很强的通用性：
- 行动：是否在做
- 能力：能否做到
- 态度：想不想做

这三个维度：
- 相对独立（不完全重叠）
- 高度相关（共同决定主体表现）
- 广泛适用（适用于多数主体评估场景）

**但这不是唯一选择。**

在其他意图下，三个维度可能完全不同：
- 评估投资项目：收益、风险、时机
- 选择餐厅：口味、价格、距离
- 评估城市：机会、环境、成本

**记住：维度由意图决定，不是固定的模板。**

A/Q/T只是在"评估主体"这个最常见的场景下，被验证为有效的一组维度。

---

## 判断的形成：从顺序到整体

三维结构的形成不是瞬间的，而是有一个过程。

**判断的形成是顺序的：**

你面试那个候选人时，你的注意力实际上是依次聚焦的：

1. 他在回答问题（行动的一种形式）→ 观察到"表现积极"
2. 他的回答内容（能力的展现）→ 判断"技术过硬"
3. 他的表情、语气（态度的信号）→ 感觉"很有意愿"

这三个判断不是同时发生的，而是在几分钟的面试过程中依次形成的。

**但判断完成后会被压缩成整体：**

面试结束时，你大脑里不是分别存着三个独立的判断：

- "行动：+0.7"
- "能力：+0.8"
- "态度：+0.9"

而是被压缩成了一个整体印象：

- "这人不错"

这个"不错"是三个维度的综合压缩结果。

**更关键的是：哪些维度会被压缩进来？**

面试场景下，你可能注意到了：

- 能力（因为他在展示）
- 态度（因为他在表达）

但**没有充分注意到"真实的行动力"**，因为：

- 面试场景本身无法完全展现行动力
- "回答问题"这种行动和"推进工作"这种行动不是一回事
- 你的注意力被"能力"和"态度"占据了

所以你形成的实际上是一个**不完整的三维结构**：

- 能力：+（清晰）
- 态度：+（清晰）
- 行动：?（模糊或被忽略）

你的大脑自动填补了"行动"这个维度：

- "能力强+态度好 → 行动应该也没问题"
- 这是一种**自动推断**，不是真实观察

三个月后，当你发现他不推进工作时，"行动-"这个真实判断才进入，整个三维结构才真正完整。

**这时候发生了跳变：**

```
面试时（不完整）：
- 能力：+
- 态度：+  
- 行动：+（推断的，不是真实的）
→ 整体印象：(+,+,+) "这人不错"

三个月后（完整）：
- 能力：+（验证了）
- 态度：+（验证了）
- 行动：-（真实暴露了）
→ 整体印象：(-,+,+) "这人有问题"
```


---

## 三维结构的调用：整体的瞬间感受

虽然判断的形成是顺序的，但**结构的调用是瞬间的**。

三个月后，你再想到这个人：

- 你不会依次回忆"他行动不足，能力还行，态度也好"
- 而是瞬间产生一个整体感受："这人不太行，有能力但不推进"

这个整体感受就是压缩后的三维结构被调用的结果。

**类比：**

- 判断的形成 = 拍照（逐个扫描像素，有先后顺序）
- 结构的存储 = 照片（压缩成整体）
- 结构的调用 = 看照片（瞬间看到完整画面）

看照片时你不会说"我先看左边，再看右边，再看中间"，而是"一眼就看到了整个画面"。

但这个"一眼"的完整画面，是之前逐个扫描的结果压缩而成的。

---

## 为什么容易漏掉维度？

正因为判断是顺序形成的，所以很容易漏掉某些维度：

**注意力容量有限：**

- 你一次只能聚焦一个维度
- 如果某个维度不够显著，就会被跳过
- 面试时"行动力"不够显著（因为只是在回答问题）

**场景限制：**

- 某些维度在当前场景下无法充分展现
- 面试场景无法展现"长期推进工作"的行动力

**经验推断：**

- 大脑会自动填补缺失的维度
- "能力+态度+ → 行动应该也+"
- 这种推断往往不可靠

**这就是为什么需要"完整的三维结构"：**

提醒自己：

1. 我在用哪几个维度评估？
2. 每个维度都是真实观察到的吗，还是推断的？
3. 当前场景能充分展现这些维度吗？

---

## 八个区域的不同感受

现在看这八种组合，每一种都给人完全不同的感受：

**(+,+,+)**：全力型

- 在做，能做到，想做
- 最理想的状态

**(+,+,-)**：表面型

- 在做，能做到，但不太想做
- 可能是迫于压力

**(+,-,+)**：热情型

- 在做，做不好，但很想做
- 新手或者志愿者

**(+,-,-)**：盲动型

- 在做，做不好，也不想好好做
- 最危险的状态

**(-,+,+)**：潜力型 ← 那个候选人

- 不在做，但能做到，也想做
- 可能在等机会，或者缺乏推动力

**(-,+,-)**：抵抗型

- 不在做，能做到，但不想做
- 故意不配合

**(-,-,+)**：善意型

- 不在做，做不到，但想帮忙
- 心有余而力不足

**(-,-,-)**：缺席型

- 不在做，做不到，也不想做
- 完全不适合或没阻碍

**每一种组合都是一种"模式"，都有其特定的含义和应对方式。这些组合不是标签，而是状态的快照。每个快照都可能在时间中跳变——正是这些跳变，让结构活起来。**

---

## 单个人还不够

三维结构让你看清楚一个人的状态。

但现实中，你不只是在评估一个人，而是在处理**你和他的关系**。

回到那个候选人：

- 你：(+,+,+) - 全力推进项目
- 他：(-,+,+) - 有能力有意愿但不行动

这不是两个独立的评估，而是**一个关系结构**。

你的(+,+,+)遇到他的(-,+,+)，会产生什么？

- 你会感到沮丧（我在拼命推，他不动）
- 他可能感到压力（你的期望和他的状态不匹配）
- 项目会陷入困境（你一个人无法完成所有事）

结构不是停留在一个人身上，而是延伸到关系之中。这种"主体和客体的结构组合"，形成了一个**六维的关系空间**：

```
你(行动+, 能力+, 态度+) × 他(行动-, 能力+, 态度+)
= 3维 + 3维 = 6维
```

“你：(+,+,+) × 他：(-,+,+) = 6维关系。”这就是下一个层次：主客结构。

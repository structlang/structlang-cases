在上一章，我们论证了：共识不需要"客观本体"这个不可验证的形而上学假设。科学之所以稳定，不是因为"更接近客观"，而是因为：高频验证+广泛重叠+精确预测。

但如果共识的稳定性不依赖"客观"，那"客观"这个概念为什么如此重要？

观察一个现象：
- 科学家说"追求客观真理"
- 法官说"依据客观事实"
- 媒体说"客观报道"
- 人们说"你太主观了"

**"客观"常被用来压制不同意见、建立权威、制造等级。**

这和什么很像？

本章将揭示：**客观崇拜的神学结构**。

---

## 一、原初的状态

让我们回到最朴素的起点。

一个婴儿睁开眼睛，看到母亲的脸。他不会想"我看到的是真的吗？"他就是看到了。

你饿了，吃了饭，饱了。你不会想"我的饱是主观的还是客观的？"你就是饱了。

你被石头绊倒，摔疼了。你不会想"这疼痛符合客观实在吗？"你就是疼。

**这是最直接、最无可争议的事实。没有任何中介，没有任何怀疑的空间。**

你就是你。你看到什么就看到什么，经历什么就有什么记忆，感受什么就感受什么。

本来，一切都很简单。

## 二、一个概念的入侵

然后，有人告诉你：

**"你看到的不是真的。"**

"什么？"

"你看到的只是表象，真正的真实在你的感知之外。"

"可是，我明明看到了啊。"

"那是你的主观。你需要追求客观。"

**"什么是客观？"**

"客观就是超越你的主观的真实。"

"那我怎么知道什么是客观？"

"你永远无法完全知道，但你必须不断追求。"

"我怎么追求？"

"通过理性、通过科学、通过克服你的偏见。"

**"如果我的感受和客观不符呢？"**

"那说明你错了。你太主观了。"

---

停下来。让我们仔细看看这段对话的结构。

你有没有觉得，这个对话似曾相识？

## 三、似曾相识的对话

让我们把这段对话换个版本：

**"你的欲望是罪恶的。"**

"什么？"

"你的欲望只是肉身的冲动，真正的善在你的意志之外。"

"可是，我就是想要啊。"

"那是你的堕落。你需要追求神的旨意。"

**"什么是神的旨意？"**

"神的旨意就是超越你的意志的真理。"

"那我怎么知道神的旨意？"

"你永远无法完全理解神，但你必须不断追求。"

"我怎么追求？"

"通过祈祷、通过信仰、通过克服你的欲望。"

**"如果我的感受和神的旨意不符呢？"**

"那说明你有罪。你太自我了。"

---

**这不是巧合。**

## 四、结构性的相似

让我们把两个概念的结构放在一起看：

|特征维度|神学中的"神"|现代哲学中的"客观"|
|---|---|---|
|**超越性**|神超越人的认知<br>人无法直接见神<br>神是不可触及的绝对存在|客观超越主观的认知<br>人无法直接触及客观本体<br>客观是不可触及的绝对实在|
|**权威性**|神掌握终极真理<br>神的话语是绝对的<br>神的判断不可质疑|客观掌握终极真实<br>客观规律是绝对的<br>客观判断不可质疑|
|**对个体的要求**|你必须放弃个人意志<br>你必须服从神的旨意<br>你的感受和欲望是可疑的|你必须放弃主观偏见<br>你必须追求客观真理<br>你的感受和经验是可疑的|
|**承诺**|追随神可以得到救赎<br>信仰神可以接近真理<br>神会给你指引|追求客观可以得到真理<br>理性可以接近客观<br>客观会给你指引|
|**惩罚机制**|不信神 = 异端<br>质疑神 = 傲慢<br>追随欲望 = 堕落|太主观 = 不理性<br>质疑客观 = 反智<br>追随感受 = 偏见|
|**不可证伪性**|你无法证明神不存在<br>你看不见神不代表神不存在<br>神的方式超越人的理解|你无法证明客观不存在<br>你触及不到客观不代表客观不存在<br>客观的方式超越主观的理解|

**这不是类比，这是同构。**

## 五、一个相同的叙事

两个概念不仅结构相似，它们还遵循同样的叙事逻辑：

|叙事步骤|神学版本|客观主义版本|
|---|---|---|
|**第一步：<br>贬低原初状态**|你生来就是有罪的<br>你的肉身是污秽的<br>你的欲望是堕落的<br>你的意志是软弱的|你的感知生来就是片面的<br>你的经验是局限的<br>你的判断是偏见的<br>你的主观是不可靠的|
|**第二步：<br>建立超越性权威**|有一个神，全知全能<br>神掌握终极真理<br>神是完美的、绝对的|有一个客观世界，完整真实<br>客观掌握终极真相<br>客观是完整的、绝对的|
|**第三步：<br>指定中介和方法**|通过教会接近神<br>通过祈祷与神沟通<br>通过经文理解神意<br>通过仪式表达虔诚|通过科学接近真理<br>通过理性克服偏见<br>通过逻辑理解规律<br>通过实验验证假设|
|**第四步：<br>永恒的追求与不足**|你永远无法完全理解神<br>神的智慧无限，人的理解有限<br>但你必须不断追求，这就是信仰|你永远无法完全触及客观<br>客观世界无限，主观认知有限<br>但你必须不断追求，这就是理性|
|**第五步：<br>规训与等级**|越服从神的人越虔诚<br>越克制欲望的人越圣洁<br>建立道德等级：圣徒 > 信徒 > 异教徒|越追求客观的人越理性<br>越克服主观的人越科学<br>建立认知等级：科学家 > 理性人 > 主观者|

**共同的逻辑**：你原本的状态是不够的 → 存在超越性权威 → 通过指定方法接近 → 追求永恒但永不抵达 → 建立等级制度

## 六、不是巧合，是转换

这种结构性的相似不是巧合。

**它揭示的是：当启蒙运动推翻宗教权威后，人们并没有真正回到"我就是我"的原初状态，而是用"客观"替代了"神"。**

### 权力结构的转换

|维度|神学时代|现代|
|---|---|---|
|**核心对立**|人的意志 vs 神的意志|主观认知 vs 客观真理|
|**追求目标**|追求神的旨意|追求客观真实|
|**接近中介**|教会、祈祷、经文|科学、理性、实验|
|**规训话语**|"你太自我了"|"你太主观了"|
|**权威垄断**|教会垄断解释权|科学共同体垄断解释权|
|**等级标准**|信仰虔诚程度|理性客观程度|

**权力结构没有被打破，只是换了个名字。**

原来是神的话语压制人的意志，现在是客观真理压制主观经验。

### 为什么需要这个转换？

**从社会控制的角度**：

如果每个人都说"我看到什么就是什么"，如何协调？如何建立共识？如何形成集体行动？

**传统解决方案**：引入超越性权威

- 神学时代：神说什么就是什么，大家都服从神
- 现代：客观说什么就是什么，大家都追求客观

这提供了一个超越个体差异的参照系，使得社会协调成为可能。

**但代价是什么？**

- 贬低了个体的直接经验
- 制造了个体与权威之间永恒的差距
- 建立了认知的等级制度
- 让人们怀疑自己、克制自己

## 七、客观的真正作用

让我们诚实地承认：引入"客观"这个概念确实解决了一些问题。

### 客观概念的积极作用

**1. 提供了共同参照**

- 当两个人看法不同时，可以说"让我们看看客观事实"
- 这给出了一个暂时的协调方案

**2. 推动了科学协作**

- 科学家们需要一个共同的标准来评价理论
- "客观验证"提供了这个标准

**3. 建立了评价机制**

- 需要区分"严格验证的知识"和"个人臆测"
- "符合客观"成为一个筛选标准

**4. 抵制了相对主义**

- 防止陷入"各说各话"的混乱
- 提供了超越个体意见的判据

**这些都是真实的功能。**

### 但问题在于

**我们为了这些功能，付出了不必要的本体论代价。**

我们不需要假设有一个"超越认知的客观本体"，也能实现上述功能：

|功能需求|传统方案（形而上学）|替代方案（方法论）|
|---|---|---|
|共同参照|"符合客观本体"|多主观的稳定重叠|
|科学协作|"发现客观规律"|高频验证的共识沉淀|
|评价机制|"是否客观"|可重复性、预测力、一致性|
|抵制相对主义|"客观真理存在"|承认共识有不同的稳定性和权重|

**换句话说**：

❌ 不需要："有一个独立于认知的客观本体存在"（形而上学假设）  
✅ 只需要："建立可操作的可靠性标准"（方法论工具）

## 八、区分两个层面

这里必须做一个至关重要的区分，否则会导致严重的误解。

### 客观本体 vs 客观性标准

|维度|客观本体<br>（Objective Reality as Metaphysical Entity）|客观性标准<br>（Objectivity as Methodological Criterion）|
|---|---|---|
|**定义**|独立于所有认知存在的终极实在|判断认知可靠性的操作标准|
|**特征**|超越的、不可触及的、绝对的|可重复验证、多视角一致、预测有效|
|**性质**|形而上学假设，不可证伪|方法论工具，可操作|
|**地位**|**这是神学结构，可以悬置**|**这是科学方法，必须保留**|

### 科学追求的是什么？

**传统说法**："科学发现客观真理"

这个说法混淆了两个层面：

- 如果"客观真理"指"符合超越性本体"→ 这是形而上学主张，不可验证
- 如果"客观真理"指"经过严格验证的可靠知识"→ 这是方法论操作，完全可行

**更准确的说法**："科学建立高度可靠的共识"

- 通过可重复实验
- 通过多视角验证
- 通过预测力检验
- 形成稳定的多主观重叠

**这不需要假设"背后有客观本体"**

### 我们的批判对象

|我们批判的|我们不批判的|
|---|---|
|✅ 把"客观"当成超越性本体|❌ 科学方法|
|✅ 把"追求客观"当成接近神性真理|❌ 可验证性标准|
|✅ 用"客观"来贬低主观经验|❌ 可重复性要求|
|✅ 把"客观假设"当成不可质疑的前提|❌ 严格的论证|

**我们只是说**：这些好东西不需要形而上学的"客观本体"来支撑。

## 九、科学不需要神学

这是整篇文章最重要的论点：

**科学的有效性不依赖于"客观本体"的假设。**

### 科学如何运作

|步骤|传统理解（依赖客观本体）|替代理解（不依赖客观本体）|
|---|---|---|
|**前提**|存在一个客观世界|科学家在各自的主观视角内观察|
|**过程**|科学家通过观察接近这个客观世界|通过严格方法使主观观察可比较、可重复|
|**标准**|理论越接近客观，就越正确|大量主观观察呈现高度一致性时，形成共识|
|**验证**|无法验证（无法跳出主观比较）|这个共识具有预测力、可应用|

**问题**：传统理解中，你永远无法验证"接近客观"，因为你无法跳出主观来比较。

**替代理解**：不需要假设第一步，后面的过程照样有效。

### 真实案例：牛顿力学

|叙事|传统（客观本体叙事）|替代（多主观重叠叙事）|
|---|---|---|
|**成就**|牛顿发现了"客观的力学规律"<br>这些规律"真实存在"于宇宙中|牛顿总结了在宏观、低速范围内极度稳定的多主观重叠<br>无数观察者在这个范围内得到高度一致的结果|
|**成功**|这个理论"符合客观"|这个重叠模式有强大的预测力|
|**局限**|后来发现在极端条件下不成立<br>说明牛顿"接近但没完全接近客观"|后来发现在微观、高速范围内这个重叠模式失效<br>相对论和量子力学总结了新范围内的稳定重叠|
|**需要假设**|需要假设"客观规律"存在|只需要描述"稳定重叠"的范围|

**科学实践有任何差别吗？**

没有。科学家该做什么还是做什么：做实验、验证可重复性、检验预测力、修正理论。

### 为什么后者更好？

| 优势           | 说明                                         |
| ------------ | ------------------------------------------ |
| **1. 更诚实**   | 不假装能触及不可触及的东西<br>承认我们只能在主观视角内工作            |
| **2. 更简洁**   | 不需要不可证伪的形而上学假设<br>奥卡姆剃刀：不必要的假设应该被剔除        |
| **3. 更清晰**   | 理论修正不再是"发现之前的理论不够客观"<br>而是"在新的范围内建立新的稳定重叠" |
| **4. 避免神学化** | 不把科学变成追求超越性真理的宗教<br>保持科学作为可操作方法的本质         |

## 十、硬现实的抵抗性

有人可能会问：

**"如果没有客观本体，你怎么解释'硬现实'的抵抗性？"**

"我主观认为我能飞，但我跳下去还是会摔。是什么在'抵抗'我的主观？难道不是客观世界吗？"

这是一个重要的问题。但问题的前提本身就错了。

### "摔"不是硬约束，而是条件依赖的

让我们仔细拆解"跳下去会摔"这个看起来"绝对硬"的约束。

**"跳楼会摔"成立，需要满足以下所有条件**：

| 条件类型       | 具体条件                            |
| ---------- | ------------------------------- |
| **物理条件**   | 地球重力场（9.8m/s²）<br>足够的高度<br>无缓冲物 |
| **生物条件**   | 活着的身体<br>未经特殊训练<br>骨骼强度有限       |
| **认知条件**   | 有高度感知能力<br>有伤害预期<br>理解"摔"的含义    |
| **意图条件**   | 在意自己的安危<br>想要避免受伤               |
| **时间窗口条件** | 在清醒窗口（不是梦境）<br>在地球窗口（不是太空）      |

**一旦任何条件改变，"硬约束"就消失或改变**

### 反例：条件改变时"摔"消失

|情况|哪个条件改变了|结果|
|---|---|---|
|**太空站**|无地球重力场|跳"下去"不会摔<br>"硬约束"完全消失|
|**死人**|无意识主体|物理上会撞击地面<br>但"摔"作为有意义的显现不存在|
|**体操运动员**|经过专业训练<br>有缓冲技巧|从高台跳下完美落地<br>不会受伤|
|**草履虫**|无高度感知<br>无伤害预期|没有"摔"这个概念<br>对它来说不存在"高度"|
|**梦中**|非清醒窗口|可能飞起来<br>可能安全落地<br>"会摔"的规律不成立|

### "硬约束"的真相

**所谓"硬约束"的真相是**：

在地球上、清醒状态下、对普通活人而言，"跳会摔"这个经验在极广条件范围内稳定重复，因此**看起来"硬"**。

但这不是"超越条件的绝对约束"，而是**"条件依赖的高稳定性"**。

**符号化表达**：

```
"跳→摔"的稳定性 = f(条件满足度)

当条件满足度 = 100%（地球、清醒、活人、普通状态）
  → 稳定性 ≈ 99.99%
  → 看起来"硬"

当条件满足度 < 100%（太空、梦中、死人）
  → 稳定性 → 0
  → "硬约束"消失

没有条件满足度 = 恒定100%的情况
因此没有真正的"硬约束"
```

### 与第二十三章的关系：两种视角的统一

你可能注意到：

**第二十三章说**："跳会摔"的稳定性来自高频验证+广泛重叠。

**本章说**："跳会摔"是条件依赖的，改变条件就失效。

**这两个说法冲突吗？**

不冲突。它们是同一现象的两个侧面：

```
第23章的视角（共识形成）：
"跳会摔"在地球上、对活人而言
→ 被无数人在无数情境中验证
→ 形成极度稳定的多主观重叠
→ 这就是"高频验证+广泛重叠"

第24章的视角（条件依赖性）：
"跳会摔"的稳定性
→ 依赖于特定条件（地球重力、活人身体...）
→ 改变条件，共识就改变
→ 太空中就不"摔"，梦中也不"摔"

统一理解：
"高频验证+广泛重叠"是现象
"条件依赖性"是机制

在特定条件下，因果关系高频稳定
→ 形成广泛共识
→ 看起来"硬"

改变条件，因果关系失效
→ 共识随之改变
→ "硬约束"消失
```

**关键洞察**：

"硬约束"不是"超越条件的绝对真理"，而是"在特定条件下极度稳定的共识"。

- 第23章解释：共识为什么稳定（高频+重叠）
- 第24章解释：稳定为什么有边界（条件依赖）

**两者结合，才是完整图景。**
### 其他"硬约束"的分解

### 为什么它们看起来"硬"？

**不是因为"符合客观本体"**

**而是因为三个原因**：

**1. 在极广条件范围内稳定**

- "摔"在地球上99.99%的情况下稳定
- 因此在大多数人的经验中从不例外
- 看起来"硬"

**2. 权重极高**

- 这些因果印象调用频率极高
- 从小到大无数次强化
- 在认知中权重接近1.0

**3. 多主观重叠极广**

- 几乎所有人都有相同经验
- 形成极强的共识
- 看起来"客观"

**但"硬"只是"相对稳定性高"**

**改变条件→"硬约束"立即消失**

### 真正的硬约束

**问题：那有没有真正的"硬约束"？**

**有，但不是你想的那种。**

真正的"硬约束"不是经验的归纳（如"会摔""会饱"），而是**认知活动的结构性前提**。

**回到第二十章讨论的"三大元约束"**：

| 元约束          | 含义                       | 为什么是"硬"的             |
| ------------ | ------------------------ | -------------------- |
| **信息永远有限**   | 你永远无法获取无限信息<br>显现总是压缩的   | 不依赖外部条件<br>只要认知就必然受限 |
| **处理能力有限**   | 意图聚焦下能处理的信息有限<br>必然有选择   | 不是技术问题<br>是认知的结构性约束  |
| **验证必须付出代价** | 任何验证都需要时间和资源<br>不可能无成本验证 | 不依赖具体情境<br>只要验证就有代价  |

**这些才是真正的"硬约束"**：

- 不是经验归纳（如"跳会摔"）
- 而是认知的结构性前提
- 定义了理由匹配的"游戏规则"
- 连AGI也逃不出（第20章详述）

**但即便这些，也不声称"绝对真理"**：

它们只是在"结构语言框架"内的公理。如果你用其他框架（如量子认知、无限智能...），可能有不同的"元约束"。

**我们只是说**：在我们这个框架内，这些是最底层的约束。

**这些才是真正的"硬约束"**：

- 不是经验归纳，而是认知的结构性前提
- 定义了理由匹配的"游戏规则"
- 但即便这些，也不声称"绝对真理"，只是这个框架的公理

### 结论：没有硬约束，只有权重谱

**所有显现形成一个连续的权重谱**：

```
极高权重（看起来"硬"）：
├─ 摔（地球常规条件）
├─ 饱（正常生理状态）
└─ 1+1=2（标准算术）

高权重（看起来"可靠"）：
├─ 科学规律
└─ 常识

中权重（看起来"可能"）：
├─ 个人经验
└─ 小群体共识

低权重（看起来"软"）：
├─ 幻觉
├─ 梦境
└─ 个别偶然

没有绝对的分界线
只有连续的权重谱
```

**关键洞察**：

"硬约束"的幻觉来自：

- ❌ 混淆了"高权重"和"绝对真理"
- ❌ 忽略了条件依赖性
- ❌ 把"在当前条件下极度稳定"当成"超越条件的必然"

**击穿幻觉后**：

- ✅ 承认所有显现都条件依赖
- ✅ 承认"硬"只是"相对稳定性高"
- ✅ 不需要假设"超越主观的客观本体"

**最重要的是**：

这不是否认"摔"的真实性。

"摔"在地球上、对活人而言，确实极度稳定。

但这种稳定性：

- 不需要"客观本体"来支撑
- 只需要描述为"在特定条件下的高频稳定重叠"
- 承认条件依赖，不影响其实践价值

**用这种方式理解"硬约束"**：

- 更诚实（承认条件依赖）
- 更清晰（知道哪些条件）
- 更有解释力（能解释反例）
- 不需要不可证伪的形而上学假设

## 十二、不是虚无主义

必须明确指出：**拒绝"客观本体"不是虚无主义。**

### 澄清误解

|我们不是说|我们是说|
|---|---|
|❌ "一切都是相对的"|✅ 真假不是"符合客观本体"，而是"经过验证的稳定性"|
|❌ "没有真假之分"|✅ 科学和迷信的区别在于"可重复验证"而非"符合客观"|
|❌ "科学和迷信一样"|✅ 不同主观视角有不同的验证质量和稳定性|
|❌ "每个人的主观都同等有效"|✅ 我们有操作性的标准来判断可靠性|

### 判断标准

**如何判断一个共识的可靠性？**

|标准|说明|
|---|---|
|**可重复性**|在多大范围内可重复？|
|**稳定性**|在多长时间内保持稳定？|
|**一致性**|多少主观视角达成一致？|
|**预测力**|能否准确预测未来经验？|
|**可证伪性**|是否可以被检验、被推翻？|

**这些都是可操作的标准，不需要"客观本体"**

### 科学的特殊地位

科学之所以可靠，不是因为"更接近客观本体"，而是因为：

|特征|说明|
|---|---|
|**极高的可重复性**|任何人可重复实验|
|**极强的稳定性**|跨时空持续有效|
|**极广的一致性**|所有主观视角一致|
|**极准的预测力**|精确预测未来|
|**极强的可证伪性**|可以被检验推翻|

**这些特征赋予科学共识特殊地位，而不需要诉诸"客观本体"**

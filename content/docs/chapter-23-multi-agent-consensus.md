## Opening: Two Judgments, Two Different Fates

**Judgment A: "The Earth is round"**

- Proposed: Ancient Greece (6th century BC)
- Current status: 100% consensus among global scientists
- Stability duration: 2500+ years (and continuing)
- Challengers: Extremely few (viewed as heretics)

**Judgment B: "A certain influencer is very popular"**

- Proposed: A certain month in 2023
- Current status: Already forgotten
- Stability duration: 3 months
- Challengers: No one cares enough to challenge

**Both are "judgments held by multiple people"—why such different fates?**

Traditional answer:

- "Because the Earth being round is an objective fact"
- "Whether an influencer is popular is subjective feeling"

**But this answer lacks explanatory power:**

- What makes "objective facts" stable?
- Doesn't consistency in "subjective feelings" count as consensus?
- How did ancient Greeks know this was an "objective fact"?

**StructLang's answer:**

The difference between the two judgments isn't "objective vs. subjective," but rather:

|Dimension|Earth is Round|Influencer is Popular|
|---|---|---|
|**Validation Frequency**|Extremely high (astronomical observation, navigation, satellites)|Extremely low (watching a few videos)|
|**Subjective Overlap**|Extremely broad (global scientists + public)|Extremely narrow (specific groups)|
|**Prediction Accuracy**|Extremely high (space, navigation all depend on this)|Extremely low (can't predict if still popular next month)|
|**Stable Condition Range**|Extremely broad (geophysical facts)|Extremely narrow (platform algorithms, collective attention)|
|**Formation Path**|Simultaneous experience + Authority transmission + Institutional solidification|Social validation (conformity)|

**Core insight: Consensus stability doesn't come from "conforming to objectivity," but from the quality of multi-agent overlap.**

## Section 1: From Single Agent to Multi-Agent

### 1.1 Framework Review

In the previous 21 chapters, we mainly discussed **single agent cognition**:

```
Single agent perspective:

My intention → My manifestation → My judgment → My causal impression

Even discussing "subject-object relations" (Chapter 5):
My perspective → Observing others → Forming judgment

All within my subjective interior
```

### 1.2 Current Extension: Multi-Agent Scenarios

But in reality, numerous multi-agent scenarios exist:

**Scenario 1: Team decision-making**

```
5 people in meeting, discussing project direction
Each has their own judgment:

A: Project [+0.8, -0.3](benefit × risk) "Should do"
B: Project [+0.5, -0.7](benefit × risk) "Too risky"
C: Project [+0.6, -0.5](benefit × risk) "Can try"
D: Project [+0.3, -0.8](benefit × risk) "Don't do"
E: Project [+0.7, -0.4](benefit × risk) "Worth investing"

How to reach consensus?
```

**Scenario 2: Social cognition**

```
"Is a policy good or bad?"

Different groups:
├─ Beneficiaries: (+ + +)
├─ Victims: (- - -)
├─ Observers: (0 0 0)
└─ Uninformed: (? ? ?)

Does consensus exist?
```

**Scenario 3: Scientific truth**

```
"Speed of light is constant"

Early physicists:
├─ Einstein: Certain
├─ Lorentz: Doubtful
├─ Planck: Gradually accepting
└─ Others: Observing

How to go from disagreement to consensus?
```

### 1.3 Core Questions of Multi-Agent

Single agent cognition → Multi-agent cognition brings new questions:

**Question 1: How do subjective perspectives coordinate?**

- Each person has their own intention, origin, causal impressions
- How to produce consistent judgment from multiple different subjectives?

**Question 2: How does consensus emerge?**

- Not "discovering objective truth"
- Rather, some kind of overlap among multiple subjective perspectives
- How does this overlap arise?

**Question 3: Why is consensus stable?**

- Some consensus (science) extremely stable
- Some consensus (trends) vanish instantly
- Where does stability come from?

**Question 4: Who defines consensus?**

- When disagreement exists, whose judgment "counts"?
- This involves power

## Section 2: Mechanisms of Subjective Overlap

### 2.1 What Is Subjective Overlap

**Definition: Multiple agents form similar judgments about the same object under the same intention.**

Symbolic representation:

```
Agent A: Object=(+0.8)[dimension] @Intention X
Agent B: Object=(+0.7)[dimension] @Intention X
Agent C: Object=(+0.9)[dimension] @Intention X

Overlap degree ≈ 90%
Consensus: Object is positive on this dimension
```

**Key elements:**

1. Same object (all talking about this)
2. Same intention (evaluation purpose identical)
3. Similar judgment (conclusions close)

### 2.2 Three Necessary Conditions for Overlap

**Condition 1: Similar external inputs**

```
Case: Witnessing car accident

10 people at scene simultaneously:
- All saw Car A run red light
- All saw Car B get hit
- All heard collision sound

External input highly similar
→ Judgment highly consistent: "Car A's responsibility"
```

**If external input different:**

```
A only saw second half: Thinks Car B fully responsible
B only saw first half: Thinks Car A fully responsible
C heard from others: Uncertain

Different external input → Judgment divergence
```

**Condition 2: Similar intentions and origins**

```
Case: Evaluating an employee

Boss's intention: <Evaluate whether to promote>
Origin: Performance contribution
Judgment: Employee(+, ?, ?)  → Focus on performance

HR's intention: <Evaluate whether to retain>
Origin: Team harmony
Judgment: Employee(?, ?, -)  → Focus on attitude

Colleague's intention: <Evaluate whether easy to get along>
Origin: Interpersonal relations
Judgment: Employee(?, ?, +)  → Focus on personality

Same person, different intentions → Judgment divergence
```

**If intentions same:**

```
All three use intention <Evaluate overall performance>
All use three-dimensional (A, Q, T)
Origins consistent

Judgments converge: Employee(+, +, -)
Consensus forms
```

**Condition 3: Similar causal impression libraries**

```
Case: Predicting stock market

Novice investor:
Causal impression: Rising continues rising, falling continues falling
Judgment: Now rising → Will continue rising → Buy

Professional investor:
Causal impression: Rising to high tends to pull back
Judgment: Now rising → May pull back soon → Sell

Same external input (stock price rising)
Different causal impressions → Opposite judgments
```

**If causal impressions similar:**

```
All professional investors
All learned same theories
Causal impression libraries highly overlap

Judgments converge
Consensus forms
```

### 2.3 Measuring Overlap Degree (Conceptual)

**Simplified model:**

```
Overlap degree = f(External input consistency, Intention similarity, Causal impression overlap)

Extremely high overlap (90%+):
- External input: Almost identical
- Intention: Highly consistent
- Causal impressions: Extensively shared
→ Strong consensus (like scientific laws)

High overlap (70-90%):
- External input: Basically same
- Intention: Mostly consistent
- Causal impressions: Core parts shared
→ Stable consensus (like professional domains)

Medium overlap (50-70%):
- External input: Partially same
- Intention: Have commonalities
- Causal impressions: Have intersection
→ Fragile consensus (like within teams)

Low overlap (30-50%):
- External input: Significant differences
- Intention: Not fully consistent
- Causal impressions: Less overlap
→ Controversial state (like political stances)

Extremely low overlap (<30%):
- External input: Each talking past other
- Intention: Fundamentally different
- Causal impressions: Almost no intersection
→ Unable to dialogue (like different cultures)
```

### 2.4 Why Scientists Easily Reach Consensus

**Characteristics of scientific community:**

```
External input:
- Standardized experiments
- Repeatable validation
- Instrument measurement (reduces subjective differences)
→ Input highly consistent

Intention:
- Common goal: Understanding natural phenomena
- Common standards: Prediction accuracy, falsifiability
- Common origin: Empiricism
→ Intention highly unified

Causal impressions:
- Common training: Physics/chemistry/math education
- Common paradigm: Current scientific theory framework
- Common methodology: Scientific methodology
→ Causal impression libraries extensively overlap

Result:
Overlap degree extremely high (95%+)
→ Consensus extremely easy to form and extremely stable
```

**Contrast: Art critics struggle to reach consensus**

```
External input:
- Same artwork, experience highly personalized
- No "instrument measurement"
→ Input same, but subjective processing varies greatly

Intention:
- Some focus on technique
- Some focus on emotion
- Some focus on ideas
→ Intentions dispersed

Causal impressions:
- Different schools, different training backgrounds
- Diverse aesthetic standards
→ Low causal impression library overlap

Result:
Low overlap degree (30-50%)
→ Hard to form stable consensus
→ "Art has no definite answer"
```

## Section 3: Consensus Formation Paths

### 3.1 Path 1: Simultaneous Experience (Strongest Path)

**Mechanism: Multiple agents simultaneously experience same event**

```
Case: Earthquake

When earthquake occurs:
- Everyone simultaneously feels shaking
- External input compulsory, synchronous, irrefutable

Immediately forms consensus: "Just had earthquake"

Characteristics:
- Formation speed: Extremely fast (seconds)
- Stability: Extremely high (undeniable)
- Scope: All present
```

**Why this path strongest:**

1. **External input forcibly unified**
    
    - Not "heard about," is "experienced"
    - Eliminates distortion in transmission
2. **Intention automatically aligned**
    
    - Strong event forcibly activates same intention: <Understand what just happened>
    - No negotiation needed
3. **Bypasses causal impression differences**
    
    - Direct experience precedes explanation
    - "It happened" is consensus, "why it happened" can be discussed later

**Other examples:**

- Crowd-witnessed accidents
- Collectively watched game results
- On-site performance effects
- Astronomical phenomena (solar eclipse, meteor shower)

**Limitations:**

- Requires simultaneous presence (spatiotemporal constraint)
- Can only form consensus on "what happened"
- May still disagree on "what it means"

### 3.2 Path 2: Authority Transmission (Most Efficient)

**Mechanism: Believing what authorities say, no need to verify personally**

```
Case: Historical events

"Qin Shi Huang unified six kingdoms in 221 BC"

Vast majority:
- Haven't personally verified
- Trust historians
- Trust textbooks
- Form consensus

Characteristics:
- Formation speed: Fast
- Stability: Depends on authority's stability
- Scope: Authority's influence range
```

**Why effective:**

1. **Reduces cognitive cost**
    
    - Don't need everyone to verify personally
    - Social division of labor: Experts verify, public trusts
2. **Borrows others' causal impressions**
    
    - Authorities have professional training
    - Their causal impression libraries more complete
    - Ordinary people borrow their judgments
3. **Institutional support**
    
    - Academic systems, publication review, education systems
    - Enhance authority's credibility

**Authority transmission hierarchy:**

```
First tier: Direct authority
Scientists → Scientific community
"Einstein said" → Physicists all believe

Second tier: Institutional authority
Textbooks, academic journals, government documents
"Written in books" → Students all believe

Third tier: Media authority
News reports, documentaries, authoritative commentary
"CCTV said" → Public all believes

Fourth tier: Social authority
"Everyone says" → Individuals follow
```

**Risks:**

```
What if authority is wrong?

Case: Bloodletting therapy
Medieval medical authorities: Sick need bloodletting
→ Forms consensus
→ Persists hundreds of years
→ Later proven wrong

Authority transmission stability = Authority correctness × Authority status

If authority status high but judgment wrong → Stable false consensus
```

### 3.3 Path 3: Social Validation (Conformity Effect)

**Mechanism: Observing others' behaviors/judgments, then following**

```
Case: Restaurant choice

You're on unfamiliar street, see two restaurants:
Restaurant A: Queue of 20 people at door
Restaurant B: Empty

You have no other information

Social validation:
"So many queuing, must be good" → Choose A

Consensus forms: Restaurant A is good
```

**Mechanism analysis:**

1. **Borrowing others' judgments**
    
    - "20 people all chose A, they can't all be wrong"
    - Use group judgment to replace own judgment
2. **Information cascade**
    
    ```
    1st person: Based on own judgment chooses A
    2nd person: Sees 1 person at A, chooses A
    3rd person: Sees 2 people at A, chooses A
    ...
    20th person: Sees 19 people at A, chooses A
    
    Later people increasingly don't base on own judgment
    But based on "others' choices"
    ```
    
3. **Self-reinforcement**
    
    ```
    More people choose A → A looks better
    A looks better → More people choose A
    
    Positive feedback loop
    ```
    

**Power of social validation:**

```
Case: Popular trends

Certain fashion style starts trending:
T0: 10 people wear → "A bit special"
T1: 100 people wear → "This is a trend"
T2: 1000 people wear → "Must keep up"
T3: 10000 people wear → "Not wearing means outdated"

Consensus rapidly forms and reinforces
```

**Risk: Cascade errors**

```
Case: Financial bubbles

T0: Asset price normal
T1: Few people bullish, start buying
T2: Price rises, more people follow
T3: "Everyone buying, must be right"
T4: Crazy chasing, bubble forms
T5: Collapse

Social validation created false consensus
"Everyone bullish" ≠ "Really worth this price"
```

### 3.4 Path 4: Institutional Solidification (Most Enduring)

**Mechanism: Writing consensus into institutions, laws, textbooks**

```
Case: Law

"Murder is illegal"

This consensus:
- Written into criminal law
- Transmitted through education
- Reinforced through law enforcement
- Cross-generational inheritance

Forms extremely stable consensus
```

**Characteristics of institutional solidification:**

1. **External coercive force**
    
    ```
    Not "everyone thinks"
    But "non-compliance means punishment"
    
    Even if individual doesn't agree, must comply
    → Behavioral level forced unification
    ```
    
2. **Cross-temporal transmission**
    
    ```
    After institutionalization:
    - No need for each generation to debate anew
    - Transmitted directly through education
    - Becomes "common sense"
    
    Greatly reduces consensus maintenance cost
    ```
    
3. **Self-cycling**
    
    ```
    Institution → Behavior → Reinforces causal impression → Consolidates institution
    
    "Law prohibits theft"
    → Everyone doesn't steal
    → Forms causal impression: "Theft=punishment"
    → Further supports law
    ```
    

**Institutional solidification levels:**

|Level|Example|Stability|
|---|---|---|
|Constitutional|National sovereignty, fundamental rights|Extremely stable (decades-centuries)|
|Legal|Criminal law, civil law|High stability (decade-level)|
|Policy|Education policy, tax policy|Medium stability (year-level)|
|Standards|Industry standards, professional codes|Medium-low stability|
|Conventions|Social etiquette, dress codes|Low stability (easily changes)|

**Case: Institutional solidification of scientific education**

```
How "law of universal gravitation" becomes consensus:

1. Newton proposes (1687)
2. Scientists verify and accept
3. Written into textbooks (authority transmission)
4. Becomes physics education requirement (institutional solidification)
5. Generations learn through education
6. Becomes "common sense"

Now:
Consensus of billions globally
Extremely high stability
```

### 3.5 Comparing Four Paths

|Path|Formation Speed|Stability|Scope|Cost|Risk|
|---|---|---|---|---|---|
|**Simultaneous Experience**|Extremely fast|Extremely high|Those present|None|Requires presence|
|**Authority Transmission**|Fast|High-Extremely high|Authority's influence range|Low|Authority may err|
|**Social Validation**|Medium-fast|Low-Medium|Conformists|Extremely low|Cascade errors|
|**Institutional Solidification**|Slow|Extremely high|Institution's jurisdiction|High|Rigidity, hard to change|

**Combined paths strongest:**

```
Scientific laws:
Simultaneous experience (experiments repeatable)
+ Authority transmission (scientist consensus)
+ Institutional solidification (textbooks)
→ Extremely high stability

Popular trends:
Only social validation
→ Extremely low stability
```

## Section 4: Consensus Stability Spectrum

### 4.1 Extremely Stable: Scientific Laws, Mathematical Truths

**Characteristics:**

```
Validation frequency: Extremely high (millions of times)
Subjective overlap: Extremely broad (global scientists + users)
Prediction accuracy: Extremely precise (quantified to multiple decimal places)
Stable conditions: Extremely broad (within applicable scope)
Formation path: Simultaneous experience + Authority transmission + Institutional solidification

Examples:
- Law of energy conservation
- Pythagorean theorem
- Constancy of speed of light

Window length: Century-level (within applicable scope)
```

**Why extremely stable:**

1. **Repeatable validation**
    
    - Anyone can repeat experiments
    - External input highly standardized
    - Eliminates individual differences
2. **Prediction accuracy**
    
    - Precise quantification
    - Widely applied (engineering, technology)
    - Each application is a validation
3. **Institutional guarantee**
    
    - Education system inheritance
    - Scientific community maintenance
    - Textbook solidification
4. **No conflicts of interest**
    
    - Newton's laws harm no one
    - No one has motive to overturn (within macro low-speed range)

### 4.2 High Stability: Laws, Cultural Traditions

**Characteristics:**

```
Validation frequency: High (daily application)
Subjective overlap: Broad (social members)
Prediction accuracy: Medium-high (predictable consequences)
Stable conditions: Specific social scope
Formation path: Authority transmission + Institutional solidification

Examples:
- Legal provisions
- Traditional festivals
- Moral norms

Window length: Decade-century level
```

**Why high stability:**

1. **Institutional coercion**
    
    - Lawbreaking has punishment
    - External pressure maintains
2. **Generational inheritance**
    
    - Transmitted through education/family
    - Becomes part of cultural identity
3. **Social coordination needs**
    
    - Need common rules
    - Maintain social order

**But not as stable as science because:**

- Cross-cultural inconsistency (Chinese law ≠ US law)
- May have conflicts of interest (some benefit some hurt)
- Not based on repeatable validation (but social negotiation)

### 4.3 Medium Stability: Industry Conventions, Professional Standards

**Characteristics:**

```
Validation frequency: Medium (frequent within profession)
Subjective overlap: Medium (within industry)
Prediction accuracy: Medium (industry experience)
Stable conditions: Specific industry
Formation path: Experience accumulation + Authority transmission

Examples:
- Programmer coding standards
- Doctor diagnosis procedures
- Lawyer practice codes

Window length: Year-level
```

**Why medium stability:**

1. **Professional consensus**
    
    - High overlap within industry
    - Outsiders don't care
2. **Practical validation**
    
    - "This works" experience accumulation
    - But not as rigorous as science
3. **Professional pressure**
    
    - Non-compliance criticized by peers
    - Affects professional reputation

**Weaker than law because:**

- No coercive force
- Narrower scope
- More susceptible to technological changes

### 4.4 Low Stability: Popular Trends, Online Hot Topics

**Characteristics:**

```
Validation frequency: Extremely low (mainly following trends)
Subjective overlap: Narrow and rapidly changing
Prediction accuracy: Extremely low (unpredictable)
Stable conditions: Extremely narrow (specific time, platform, group)
Formation path: Mainly social validation

Examples:
- A certain influencer is popular
- A certain meme is trending
- A certain topic goes viral

Window length: Week-month level
```

**Why low stability:**

1. **No substantial validation**
    
    - Just "everyone talking about it"
    - No predictive power
    - No practical value
2. **Attention scarcity**
    
    - People's attention limited
    - New hot topics constantly emerge
    - Old hot topics forgotten
3. **No institutional support**
    
    - Won't be written in textbooks
    - Won't become law
    - Purely informational level

**Case: Rise and fall of an influencer**

```
T0: Release viral video
T1: Social validation starts, followers surge
T2: "Whole internet watching them"
T3: Peak
T4: New influencer appears, attention shifts
T5: "Who are they?"

Window length: 3 months
```

### 4.5 Extremely Unstable: Emotional Resonance, Collective Panic

**Characteristics:**

```
Validation frequency: None (pure emotion)
Subjective overlap: Instantaneously extremely high, rapidly disintegrates
Prediction accuracy: None
Stable conditions: Extremely narrow (specific situation)
Formation path: Social validation + Emotional contagion

Examples:
- Financial panic (bank runs)
- Crowd emotions in squares
- Panic caused by rumors

Window length: Hour-day level
```

**Why extremely unstable:**

1. **Pure emotion-driven**
    
    - No rational foundation
    - Emotion subsides, consensus collapses
2. **Information cascade extremely fast**
    
    - "Everyone running, I run too"
    - No verification, just following
3. **Cannot maintain afterwards**
    
    - After calming realize "unnecessary"
    - Cannot be institutionalized
    - Becomes "what were we thinking"

**Case: Bank run**

```
T0: Rumor "bank going bankrupt"
T1: Few people withdraw money
T2: Queue getting longer
T3: "Everyone withdrawing, must be problem"
T4: Collective panic, bank run
T5: Bank suspends operations
T6: Government clarifies, panic subsides
T7: "How could we believe that?"

Window length: 1-2 days
```

### 4.6 Stability Spectrum Summary

```
Extremely stable (century-level)
  ├─ Scientific laws
  └─ Mathematical truths
  
High stability (decade-century)
  ├─ Laws
  └─ Cultural traditions
  
Medium stability (year-level)
  ├─ Industry conventions
  └─ Professional standards
  
Low stability (month-level)
  ├─ Popular trends
  └─ Online hot topics
  
Extremely unstable (day-level)
  ├─ Emotional resonance
  └─ Collective panic
  
Determining factors:
Validation frequency × Subjective overlap × Prediction accuracy × Condition range × Formation path
```

## Section 5: Power Effects of Consensus

### 5.1 Defining Consensus Is Wielding Power

**Core insight: Whoever has the right to define what consensus is wields power.**

```
Case: Definition of disease

Historically:
"Homosexuality is mental illness" ← Medical authority definition
→ Consensus forms
→ Homosexuals treated, discriminated

1973:
American Psychiatric Association votes: Homosexuality not disease
→ Consensus changes
→ Rights situation changes

Definitional power = Power
```

**Mechanism:**

1. **Definition determines normal/abnormal**
    
    ```
    Authority says: X is disease → X gets treated
    Authority says: X not disease → X gets accepted
    
    Definitional boundaries are power boundaries
    ```
    
2. **Definition controls resources**
    
    ```
    Medical definition → Insurance coverage
    Legal definition → Criminal or not
    Educational definition → Included in curriculum or not
    
    Definition → Resource allocation
    ```
    
3. **Definition shapes behavior**
    
    ```
    Defined as "illness" → Seek treatment
    Defined as "crime" → Avoid doing
    Defined as "virtue" → Pursue doing
    
    Definition → Behavioral guidance
    ```
    

### 5.2 Who Has Definitional Power

**Scientific authority:**

```
Scientists have power to define:
- What is "disease"
- What is "healthy"
- What is "normal"

Why?
- Professional training
- Institutional recognition
- Social trust

Consequences:
Their definitions become consensus
→ Shape everyone's behavior
```

**Legal authority:**

```
Judges/legislators have power to define:
- What is "legal"
- What is "criminal"
- What is "rights"

Consequences:
Their definitions have coercive force
→ Direct control over behavior
```

**Cultural authority:**

```
Media/education system have power to define:
- What is "beautiful"
- What is "success"
- What is "proper"

Consequences:
Their definitions shape values
→ Indirect control over choices
```

### 5.3 Definitional Power's Hidden Nature

**Appears neutral:**

```
"We're just describing facts objectively"
"We're just following scientific standards"
"We're just enforcing law"

Seems:
- No self-interest
- Pure objective
- Just doing job
```

**Actually hidden power:**

```
But:
- They choose which facts to emphasize
- They set what standards are "scientific"
- They interpret what law "means"

These choices:
- Not neutral
- Reflect specific stance
- Serve specific interests
```

### 5.4 Contesting Definitional Power

**Historical cases:**

```
Women's rights movement:
Contest definition of "women's proper role"

Old definition (male authority):
"Women should stay home"

New definition (feminist movement):
"Women can enter any field"

Struggle:
Who has right to define "women's proper role"?
```

**Contemporary cases:**

```
Mental health diagnosis:
DSM (Diagnostic Manual) has enormous power

What gets included/excluded?
- 1973: Homosexuality removed
- Debate continues: Other conditions?

Stakes:
- Affects millions' lives
- Determines treatment/not
- Influences social attitudes
```

## Section 6: Consensus Change and Resistance

### 6.1 Why Consensus Changes

**Reason 1: External conditions change**

```
Case: Gender roles

Agricultural era:
Physical strength important → Men dominate labor
Consensus: "Men work outside, women inside"

Industrial era:
Machines reduce strength need → Women can work
Consensus begins changing

Information era:
Mental labor dominates → Gender差异 diminishes
Consensus: "Gender equality"

External conditions → Consensus follows
```

**Reason 2: New information accumulates**

```
Case: Smoking

1950s:
Limited research, social acceptance
Consensus: "Smoking no big deal"

1960s-80s:
Massive research accumulates
Evidence: Lung cancer, heart disease linkage

Now:
Scientific consensus: "Smoking extremely harmful"
→ Public consensus changed
→ Policy changed (bans, taxes)
```

**Reason 3: Power structure shifts**

```
Case: Colonial discourse

Colonial era:
European power dominates
Consensus: "Colonialism brings civilization"

Post-colonial era:
Former colonies gain voice
New consensus: "Colonialism was exploitation"

Power shift → Discourse shift → Consensus shift
```

### 6.2 Resistance to Consensus Change

**Source 1: Vested interests**

```
Those benefiting from old consensus
Have motive to resist change

Example: Tobacco industry
- Fund contrary research
- Attack scientists
- Lobby politicians
- Delay policy change

Goal: Prolong old consensus window
```

**Source 2: Cognitive inertia**

```
Changing consensus means:
- Relearning
- Overturning prior investment
- Admitting previous error

Too painful → Prefer maintaining old consensus

Example: Senior scholars in paradigm shifts
```

**Source 3: Institutional solidification**

```
Old consensus written into:
- Textbooks
- Laws
- Professional training

Huge cost to change
→ Resists change
```

### 6.3 Process of Consensus Change

**Stage 1: Minority challenges**

```
Few people question old consensus
Provide new evidence/perspective

Most people:
- Dismiss
- Attack
- Ignore

Challengers:
- Marginalized
- Called "heretics"
- Face professional risks
```

**Stage 2: Evidence accumulation**

```
More research supports new view
```

```
When enough people accept new view
Power balance tips

Turning point:
```

```
New view becomes mainstream
Written into textbooks, policies

Old view:
- Becomes "outdated"

- Historical curiosity

New consensus stabilizes
```

```
Key scientists accept

Stage 4 (1750-1850):
Scientific authority fully accepts
Becomes new common sense

Total time: ~150 years
```

```
Even knowing old consensus problematic
But no better option

Example: Certain imperfect theories
"Though imperfect, it's our best explanation currently"
```

## Section 7: False Consensus

### 7.1 What Is False Consensus

**Definition: Appears everyone agrees, actually many disagree but stay silent.**

```
Surface: 100% support X
Reality: 50% support, 50% oppose but silent

False consensus = Suppressed/hidden disagreement
```

### 7.2 Spiral of Silence

**Mechanism:**

```
Stage 1:
Media/authority repeatedly express view A
→ A appears "mainstream"

Stage 2:
Those holding view B:
"Everyone supports A, only I don't agree"
→ Fear isolation
→ Stay silent

Stage 3:
Because B supporters silent
→ A appears even more "mainstream"
→ B supporters even less dare speak
→ Spiral downward

Result:
False consensus "everyone supports A"
Reality: Many support B, just don't say
```

**Case: A certain policy**

```
Government/media heavily promote: "This policy is great"

Public:
- 30% genuinely support
- 40% dissatisfied but don't dare say (fear isolation/suppression)
- 30% unaware

Surface: Appears "broad consensus"
Reality: Majority dissatisfied but silent

Risk:
False consensus accumulates tension
→ Suddenly erupts
→ "How did everyone suddenly oppose?"
```

### 7.3 Surface Unity, Internal Disagreement

**Case: "Unanimous approval" at meeting**

```
Scenario: Company meeting

Boss: "Does everyone agree with this plan?"

Surface: Everyone nods
"Unanimously approved"

Reality:
- 2 people genuinely support
- 5 people have doubts but don't dare say
  (fear being seen as "uncooperative")
- 3 people think it won't work but don't want to offend boss

False consensus forms
```

**Consequences:**

```
Plan execution:
- Poor execution (because not genuinely committed)
- Problems surface
- Boss: "Didn't you all agree?"
- Employees: "..."

Cost of false consensus
```

### 7.4 Conformity Pressure

**Mechanism:**

```
Observe others' choices
→ Doubt own judgment
→ Change expression (not change belief)

Case: Asch conformity experiments
Obviously wrong answer
But if majority chooses
→ Individual follows (at least superficially)
```

**Real examples:**

```
Certain view massively forwarded on social media
→ "So many support, must be right"
→ Even if you have doubts, follow and forward
→ Assist false consensus

Reality:
Many forwarding also have doubts
Just everyone conforming
```

### 7.5 Identifying False Consensus

**Signal 1: Only one voice**

```
All media, all people saying same thing
→ Suspicious

Real consensus:
Should have discussion, disagreement, detail differences

If completely uniform
→ May be different voices suppressed
```

**Signal 2: Lack specific arguments**

```
Only slogans, no argumentation
"Everyone supports"
"This is consensus"
"No need to discuss"

Real consensus:
Based on argumentation, evidence, testability

If refuses discussion
→ May be false consensus
```

**Signal 3: No questioning allowed**

```
Challengers suppressed:
"How can you think that?"
"Everyone agrees, just you don't"
"Is there something wrong with you?"

Real consensus:
Welcomes challenge and validation

If no questioning allowed
→ Very likely false
```

**Signal 4: What's said privately vs publicly differs**

```
Public setting: All say support
Private chat: Various complaints

Huge discrepancy → False consensus
```

### 7.6 Risks of False Consensus

**Risk 1: Accumulating tension**

```
Surface harmony, internal dissatisfaction
→ Tension continuously accumulates
→ Certain trigger event
→ Suddenly erupts

Example: Certain social movements
"How did everyone suddenly take to streets?"
Reality: Dissatisfaction long accumulated, just didn't dare say
```

**Risk 2: Wrong decisions**

```
Decision-makers think "everyone supports"
→ Make decisions based on false consensus
→ Face huge resistance during execution
→ Surprised: "Didn't everyone agree?"
```

**Risk 3: Loss of error correction mechanism**

```
No one dares raise different opinions
→ Errors cannot be pointed out
→ Wrong all the way

Example: Certain project failures
"Already knew wouldn't work, but no one dared say"
```

## Section 8: Manipulating Consensus

### 8.1 How to Manufacture Consensus

**Strategy 1: High-frequency repetition**

```
Mechanism:
Same information repeatedly appears
→ Familiarity increases
→ Mistake familiarity for correctness
→ "Feel like everyone says so"

Example: Advertising
Same slogan repeated 1000 times
→ You start believing

Techniques:
- Multi-channel repetition (TV, internet, offline)
- Multi-format repetition (text, images, video)
- Long-term repetition (continuous months)
```

**Strategy 2: Authority endorsement**

```
Mechanism:
Find authorities/celebrities/experts to support
→ Borrow their credibility
→ "Even XX says so, must be right"

Examples:
- Scientists endorse products
- Celebrities forward views
- Government officials make statements

Techniques:
- Choose authorities influential to audience
- Emphasize authority's expertise/status
- "90% of experts agree" (selective presentation)
```

**Strategy 3: Social proof**

```
Mechanism:
Show "many people already believe/participate"
→ Trigger conformity psychology
→ "Everyone doing this, I should too"

Examples:
- "Already 1 million users"
- "Whole internet discussing"
- "Your friends all forwarding"

Techniques:
- Emphasize quantity (millions, nationwide, everyone)
- Show surrounding people (people you know also believe)
- Create "not keeping up means falling behind" anxiety
```

**Strategy 4: Emotion activation**

```
Mechanism:
Activate strong emotions (fear, anger, pride)
→ Bypass rational thinking
→ Form consensus driven by emotion

Examples:
- War mobilization: "Enemy brutal" → Hatred → Consensus
- Patriotism: "Our glory" → Pride → Consensus
- Panic marketing: "Not buying means done for" → Fear → Consensus

Techniques:
- Strong images/stories
- Simplified good vs evil opposition
- Time pressure ("must act now")
```

**Strategy 5: Suppress dissent**

```
Mechanism:
Prevent different opinions from voicing
→ Create illusion of "unanimity"
→ False consensus

Methods:
- Delete posts, ban accounts (technical means)
- Stigmatize questioners ("you're XXX")
- Social punishment (isolation, suppression)

Result:
Surface "broad consensus"
Actually suppressed
```

### 8.2 How to Maintain Consensus

**Strategy 1: Institutional solidification**

```
Write into:
- Textbooks (next generation automatically accepts)
- Laws (external coercion)
- Industry standards (professional coercion)

Effect:
- No need to argue each time
- Becomes "common sense"
- Challengers viewed as ignorant
```

**Strategy 2: Periodic reinforcement**

```
Can't just promote once and stop
Need continuous reinforcement:
- Memorial days
- Rituals
- Re-emphasize during major events

Example:
Certain national ideology
→ Continuously reinforced through holidays, rituals
→ Maintain consensus
```

**Strategy 3: Control information sources**

```
Ensure:
- Mainstream media unified message
- Education system unified textbooks
- Reduce exposure to different voices

Effect:
- Reduce possibility of wavering
- Maintain consensus stability
```

**Strategy 4: Interest binding**

```
Let people benefit from this consensus
→ Have motive to maintain

Example:
Certain industry "industry rules"
→ Compliant people profit
→ Everyone has motive to maintain
→ Consensus stable
```

### 8.3 How to Break Unfavorable Consensus

**Strategy 1: Introduce counterexamples**

```
Find examples old consensus can't explain
→ Repeatedly demonstrate
→ Accumulate doubt

Example:
Old consensus: "This method works"
You:
- Find 10 failure cases
- Analyze in detail why failed
- Show to key decision-makers

Effect:
Old consensus starts wavering
```

**Strategy 2: Change narrative**

```
Same facts, different frames
→ Different consensus

Example:
Old narrative: "Overtime is dedication"
New narrative: "Overtime is exploitation"

Same behavior
Different moral judgment
```

**Strategy 3: Find new authorities**

```
Old consensus relies on old authorities
You find new authorities to endorse new view

Example:
Old consensus: Senior experts support
You: Find more persuasive experts opposing

Authority vs authority
Weaken old consensus
```

**Strategy 4: Build alternative consensus**

```
Not just criticize old
Also provide new option

Example:
Not just say "this plan won't work"
Also say "this new plan is better"

Having alternative → Easier to change
```

**Strategy 5: Wait for timing**

```
Consensus windows change
External conditions change → Consensus may loosen

Example:
Normal times: Old consensus very stable
Crisis times: Old consensus fails
→ This is timing to push new consensus

"Don't waste a crisis"
```

### 8.4 Case: Climate Change Consensus Battle

**Scientific community: Building consensus**

```
Strategies:
- Massive research validation (simultaneous experience)
- IPCC reports (authority endorsement)
- Media coverage (social dissemination)
- Education popularization (institutional solidification)

Effect:
97% scientific community consensus
"Human-caused climate change is real"
```

**Interest groups: Weaken consensus**

```
Strategies:
- Fund opposing research (create "controversy")
- Amplify uncertainty ("scientists also uncertain")
- Attack authorities ("IPCC unreliable")
- Create confusion ("climate changed before too")

Effect:
Public consensus lower than scientific community
"Seems still controversial"
```

**Power struggle:**

- Scientists: Try to build strong consensus
- Fossil fuels: Try to weaken consensus
- Battlefield: Public cognition

**Result impact:**

- If consensus strong → Policy supports emissions reduction
- If consensus weak → Policy inaction

Defining consensus = Controlling policy

## Section 9: Practical Applications

### 9.1 Building Consensus in Teams

**Step 1: Align intentions**

```
Ensure everyone:
- Same goal (what to achieve)
- Same origin (what standards to evaluate by)

Method:
- Explicitly discuss: "What's our goal?"
- Record after reaching agreement
- Review during subsequent decisions

Avoid:
Talking past each other, different intentions, never consensus
```

**Step 2: Unify information**

```
Ensure everyone:
- Sees same data
- Knows same background
- Accesses same cases

Method:
- Information transparent, accessible to all
- Regular sync, reduce information gap
- Before major decisions: First align information

Avoid:
Information asymmetry → Different judgments → No consensus
```

**Step 3: Build common causal impressions**

```
Team needs:
- Similar professional training
- Common experience accumulation
- Unified methodology

Method:
- Team training
- Retrospectives (precipitate causal impressions)
- Build team "knowledge base"

Effect:
Causal impression overlap → Judgments converge → Easy consensus
```

**Step 4: Full discussion, expose disagreements**

```
Don't:
Surface "unanimous approval"
Actually each has thoughts

But:
- Encourage expressing different opinions
- Deeply discuss disagreement roots
- Understand where differences lie

Effect:
- Real consensus (not false)
- Strong execution (because genuinely committed)
```

**Step 5: Unified action after decision**

```
During discussion: Full expression
After decision: Unified execution

Even if you don't fully agree
But since team decided
→ During execution no complaints, no negativity

This is organizational discipline
Not suppressing individuals
```

### 9.2 Challenging False Consensus

**When to challenge:**

```
When consensus:
- Based on wrong information
- Ignores important counterexamples
- Harms long-term interests
- Based on false public opinion

You should challenge
Even if risky
```

**How to challenge:**

**Strategy 1: Provide new information**

```
"Everyone might not have noticed this data..."
Not "you're wrong"
But "I'll supplement some information"

Reduce confrontation
Increase acceptance
```

**Strategy 2: Raise key questions**

```
"If X is true, how to explain Y?"
Not direct denial
But logical challenge

Let others discover contradictions themselves
```

**Strategy 3: Find allies**

```
First privately communicate, find others also doubtful
Then collectively express

Effect:
"Not just me thinking this"
→ Reduce "isolation" risk
→ Increase persuasiveness
```

**Strategy 4: Choose timing**

```
Don't challenge when boss in bad mood
Don't challenge when team extremely tired

Choose:
- Calm discussion moments
- Settings with time for deep analysis
- Stages when decision not yet finalized
```

**Strategy 5: Provide alternatives**

```
Not just "this is wrong"
Also "I suggest this"

Having alternative → Constructive
More likely accepted
```

### 9.3 Avoiding Blind Conformity

**Strategy 1: Independent thinking before expressing**

```
Don't:
See "everyone supports" → Immediately follow

But:
1. Based on my information, what's my judgment?
2. Does my judgment match majority?
3. If not, why?
4. Is it my information insufficient, or they didn't consider certain factors?

Then decide:
- Follow majority
- Or reserve opinion
- Or express different view
```

**Strategy 2: Be alert to social pressure**

```
When you feel:
"Not saying this, will be isolated"
"Not keeping up, will fall behind"

This is social pressure signal

Ask yourself:
- Is this genuine agreement, or considering pressure?
- Without pressure, what would I choose?

Distinguish: Real consensus vs conformity
```

**Strategy 3: Seek contrary information**

```
Actively seek:
- Voices not supporting mainstream view
- Overlooked counterexamples
- Different perspectives

Not opposing for sake of opposing
But to avoid information cocoon

Comprehensive information → Better judgment
```

**Strategy 4: Small-scale testing**

```
Don't wholesale accept certain consensus
First verify small-scale:

"Everyone says X works"
→ I first try small-scale
→ Indeed works, then expand
→ Doesn't work, then question

Practice test > Blind following
```

### 9.4 Leveraging Consensus to Advance Goals

**Identify existing consensus:**

```
In team/organization/society
What consensus already exists?

Examples:
- "Efficiency important" (organizational consensus)
- "Innovation is future" (social consensus)
- "Customer first" (industry consensus)

After identifying, leverage them
```

**Link your goals to consensus:**

```
You want to advance: New project X

Find existing consensus:
Organizational consensus: "We need innovation"

Link phrasing:
"Project X is exactly the innovation attempt we need"

Effect:
Borrow consensus power
Advance your goal
```

**Create new consensus:**

```
If existing consensus unfavorable
Create new:

Steps:
1. Provide new information/perspective
2. Find authority endorsement
3. Small-scale validate effectiveness
4. Gradually disseminate

Example:
You want to push remote work

1. Provide data: Remote efficiency doesn't drop but rises
2. Find success cases: Certain famous company fully remote
3. Small team pilot: Prove feasible
4. Disseminate: Gradually persuade more people

Eventually: Form new consensus "remote work feasible"
```

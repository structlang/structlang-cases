## 引言：不止一种方法

在第五章中，我们介绍了**主客结构**，这是一种主客并行的方法：

- 确定我的立场（主体）
- 确定对方的位置（客体）
- 六个维度同时展开
- 对称分析

当时我们提到但在实际使用中，很多人会遇到一个困惑：

**"我为什么一定要使用行动/素质/态度这样的要素来建立维度，为什么我一定要使用这样的固定的主客结构呢？"**

是的，我们从未说过方法局限于主客结构和行动/素质/态度这样的要素，纯粹只是为了方便新手入门而已，只要按照人类本身的思维方式能行得通的都是好方法，比如第十四章建立的方法。

这一章，我们介绍**另一种建立主客关系的方式：锚定镜像法**。

**核心思路：**

- 不是双方同时展开
- 而是**先锚定一方，另一方自动对位**
- 谁先被锚定，谁就主导解释路径

这是主客并行法以外的**另一个工具**。

---

## 第一节：什么是锚定镜像结构

### 1.1 定义

> **锚定镜像结构**：先在六层棋盘中固定主方的位置（锚定），另一方必然落入对位（镜像），形成对照关系。

**两个关键动作：**

**1. 锚定**

- 判断谁是局势的发起方
- 把这一方固定在最关键的一条线上
- 确定这条线为主导线

**2. 镜像**

- 主位一旦确定，对方自动落在对位
- 不需要额外选择
- 形成自然的对照关系

**核心洞察：**

**局势的解释不是天然对称的，而是由"谁先被锚定"为主，来决定整盘的推演。**

### 1.2 与主客并行法的区别

|维度|主客并行法|锚定镜像法|
|---|---|---|
|建立方式|双方同时确定，对称展开|先锚定一方，另一方自动镜像|
|起点|明确"我"的立场|判断"谁是发起方"|
|强调点|对称性|起点偏置|
|适用场景|我作为参与者，立场明确|快速切入，或者需要强调主导方|
|灵活性|六维可以自由组合|三条对照线，主线决定起局|
|典型案例|我（主体）vs 客户（客体）|面试中：候选人发起 vs 公司考察|
|核心问题|"我的六维 vs 对方的六维"|"谁在主导这个局面？"|
|分析重点|每个维度的具体状态|三条对照线的协同关系|

**关键差异：**

- **并行法**：强调"我"和"对方"同等重要，六维对称
- **锚定法**：强调"谁先动"决定了局面的解释路径，存在主导性

**两者不是对立，而是互补：**

- 当"我"的立场清晰时→用并行法
- 当需要快速判断"谁主导"时→用锚定法
- 当需要强调某条对照线时→用锚定法

### 1.3 为什么需要锚定镜像法

**场景1：不确定谁是主体**

```
A公司和B公司在谈判，我要分析这个局面。
问题：我应该把谁当主体？

并行法：需要先确定我站在谁的角度
锚定法：直接判断"谁发起谈判"→锚定发起方
```

**场景2：需要强调主导方**

```
面试场景：候选人 vs 公司
问题：这个局面谁主导？

并行法：可以分析，但主导性不明显
锚定法：锚定候选人在行动线（他主动展示）→一目了然
```

**场景3：快速切入分析**

```
需要快速判断局势
问题：六维展开太复杂

并行法：需要展开完整六维
锚定法：先锚定主线→其他两线作为辅助→快速聚焦
```

**锚定镜像法的价值：提供了一个"起点偏置"的视角。**

### 1.4 与第十四章方法的区别

在第十四章，我们介绍了**"基础-互动-目标"三层压缩**，用于从外部观察者视角分析事件。

本章的**"素质线-行动线-态度线"三条对照线**，是从参与者视角建立主客关系的方法。

**核心区别：**

|维度|第十四章方法|本章方法|
|---|---|---|
|**视角**|外部观察者|参与者之一|
|**目的**|判断事件能否成功|建立主客关系|
|**分组逻辑**|基础(前提)-互动(过程)-目标(结果)|素质(硬件)-行动(当下)-态度(意愿)|
|**适用场景**|观察外部结构演化|我作为主动方出击|
|**输出**|事件可行性判断|主客关系定位|

**举例说明：**

- **用第十四章方法**：我观察A公司和B公司谈判，判断这个合作能不能成
- **用本章方法**：我去面试/推销，判断我和对方的主客关系如何建立

**两者可以结合：**
```
第一步：用第十四章方法观察外部结构
    ↓
判断力量对比和事件可能性
    ↓
第二步：如果我要介入，用本章方法
    ↓
快速锚定我的位置，建立主客关系
```

两种方法不是对立，而是**不同场景下的工具选择**。

## 第二节：六层棋盘与三条对照线

### 2.1 六层棋盘的结构

在锚定镜像法中，六个维度被重新组织为**三条对照线**：
```
上层：态度/立场/规则
  主方态度 ↔ 对方态度
  【态度线】

中层：行动/互动/博弈  
  主方行动 ↔ 对方行动
  【行动线】

下层：资源/条件/素质
  主方资源 ↔ 对方资源
  【素质线】
```

**重要说明：维度编号的差异**

本章的分组方式与第五章不同：

- **第五章**：维度1-3是主体，维度4-6是客体（对称展开）
- **本章**：不强调1-6的编号，而是强调**三条对照线的配对关系**
  - 素质线：主方资源 ↔ 对方资源
  - 行动线：主方行动 ↔ 对方行动
  - 态度线：主方态度 ↔ 对方态度

这种差异是因为：**锚定镜像法关注的是"谁先被锚定"，而不是"谁是主体"**。

**为什么这样分组？**

这符合正常人直白的思维模式：

- **下层**：基础条件（你有什么）
- **中层**：当下博弈（你做什么）
- **上层**：规则立场（你想什么）

**三条线的逻辑关系：**

```
素质线：前提条件
    ↓
行动线：当下博弈
    ↓  
态度线：最终拍板
```

### 2.2 三条对照线的含义

#### 素质线（1↔4）

**对应内容：**

- 主方：简历、资历、能力、资源
- 对方：岗位要求、标准、期待

**作用：**

- 判断基础匹配度
- 如果素质线差距太大，其他两线再好也难成
- 这是"硬条件"

**面试案例：**

- 候选人1：3年经验、名校背景
- 公司4：要求5年经验、985背景
- 素质线：勉强匹配（略有不足）

#### 行动线（2↔5）

**对应内容：**

- 主方：临场表现、互动方式、展示能力
- 对方：考察方式、提问节奏、反馈

**作用：**

- 这是当下博弈的主战场
- 行动线的表现可以补素质线的不足
- 这是"软实力"

**面试案例：**

- 候选人2：回答清晰、逻辑严密、态度诚恳
- 公司5：提问专业、节奏把握好、有反馈
- 行动线：互动顺畅（++）

#### 态度线（3↔6）

**对应内容：**

- 主方：动机、心态、期望、价值观
- 对方：文化偏好、薪酬框架、团队氛围

**作用：**

- 这是最终拍板的决定因素
- 前两条线再好，态度线不合也会崩盘
- 这是"价值观"

**面试案例：**

- 候选人3：期望月薪2万、追求成长
- 公司6：预算1.5万、强调加班文化
- 态度线：冲突（--）

### 2.3 三条线的协同关系

三条线**不是独立的**，而是相互影响：

**正向协同：**

```
素质线匹配（++）
    ↓
行动线顺畅（++）→ 增强信心
    ↓
态度线契合（++）→ 最终达成
```

**负向传导：**

```
素质线不足（--）
    ↓
行动线压力大（-）→ 表现失常
    ↓
态度线受影响（-）→ 最终放弃
```

**补偿关系：**

```
素质线略有不足（+）
    ↓
行动线超强（++）→ 补偿素质
    ↓
态度线契合（++）→ 仍然达成

或：

素质线优秀（++）
    ↓
行动线一般（+）→ 凭素质过关
    ↓
态度线契合（++）→ 达成
```

**冲突关系：**

```
前两线都好（++++）
    ↓
但态度线冲突（--）
    ↓
最终崩盘（态度线一票否决）
```

**关键洞察：**

**行动线是最灵活的**，可以补素质、可以展现态度，是"主战场"。

### 2.4 如何选择锚定哪条线

**锚定的原则：谁发起局面，就锚定谁在哪条线。**

**判断标准：**

|场景类型|发起方特征|锚定位置|理由|
|---|---|---|---|
|面试|候选人主动展示|行动线2|候选人要"表现"|
|推销|销售主动出击|行动线2|销售要"说服"|
|谈判|提出条件的一方|行动线2|谁先提条件谁主动|
|竞标|投标方主动争取|行动线2|投标方要"竞争"|
|求职|求职者主动投递|素质线1|强调"我有什么"|
|相亲|主动约见的一方|态度线3|强调"我的意愿"|
|合作|提出合作方案的一方|行动线2|方案即行动|

**一般规律：**

- **大多数情况锚定在行动线2**（因为大多数局面是"一方主动出击"）
- **如果强调资源优势，锚定在素质线1**（如：名企高管求职）
- **如果强调态度意愿，锚定在态度线3**（如：追求者表白）

**锚定后，对方自动对位：**

- 锚定在2→对方在5
- 锚定在1→对方在4
- 锚定在3→对方在6

## 第三节：完整案例——面试局

### 3.1 场景设定

**角色：**

- 候选人张三：3年工作经验，想跳槽到一家互联网公司
- 公司HR+技术面试官：招聘一个产品经理

**面试流程：**

1. HR初筛（20分钟）
2. 技术面试（1小时）
3. 最终谈薪（30分钟）

**我们用锚定镜像法来分析这个面试局。**

### 3.2 锚定：候选人在行动线2

**为什么锚定候选人？**

因为面试由候选人主动发起：

- 候选人投递简历（发起）
- 候选人来到现场（主动）
- 候选人需要展示自己（行动）

**为什么锚定在行动线2？**

因为面试的核心就是**候选人的临场表现**：

- 回答问题
- 展示能力
- 表达意愿

**锚定后，对方自动镜像：**

```
候选人（主方）：锚定在行动线2
    ↓
公司（对方）：自动镜像在行动线5
    ↓
形成对照：候选人展示 ↔ 公司考察
```

**这就是面试的本质：2↔5的强制互动线。**

### 3.3 六层棋盘的完整展开

#### 初始状态（面试前）

**素质线（1↔4）：**

```
候选人1：
- 3年产品经验
- 带过2个项目
- 某二线互联网公司背景
- 简历还行，但不突出
状态：+ （勉强及格）

公司4：
- 要求3-5年经验
- 需要独立带项目能力
- 最好有大厂背景
状态：+ （标准不算太高，但有期待）

素质线对照：+↔+ （基本匹配，略有不足）
```

**行动线（2↔5）：**

```
候选人2（锚定点）：
- 还没开始面试
- 准备了作品集
- 心里有点紧张
状态：? （待展现）

公司5：
- 设计了标准面试流程
- 技术面试官经验丰富
- 会考察项目细节
状态：+ （准备充分）

行动线对照：?↔+ （公司占主动）
```

**态度线（3↔6）：**

```
候选人3：
- 期望月薪18K-20K
- 希望有成长空间
- 价值观：追求产品体验
状态：+ （动机明确）

公司6：
- 预算15K-18K
- 团队氛围不错
- 文化：快速迭代，能接受加班
状态：+ （有吸引力，但薪资可能不够）

态度线对照：+↔+ （有契合可能，但存在薪资gap）
```

**初始结构判断：**

```
素质线：+↔+ （基本匹配）
行动线：?↔+ （公司主动，候选人待展现）
态度线：+↔+ （有契合可能）

总体：有戏，但关键看行动线的表现
```

#### 中期演化（技术面试中）

**行动线变化：**

```
候选人2（展现）：
- 回答清晰，逻辑严密
- 展示作品集，案例详实
- 主动询问团队情况，表现出真诚兴趣
状态：++ （超出预期）

公司5：
- 面试官频频点头
- 追问了几个深度问题
- 给了正面反馈
状态：++ （满意）

行动线对照：++↔++ （互动顺畅，双向加分）
```

**行动线增强→素质线重估：**

```
候选人1（被重估）：
- 虽然背景一般，但临场表现说明能力强
- 面试官重新看待简历："可能低估了他"
状态：+ → ++ （行动线加分）

公司4：
- 标准维持不变
状态：+

素质线对照：++↔+ （候选人被拉高）
```

**态度线尚未明显变化，等待最终环节。**

#### 最终阶段（谈薪环节）

**态度线的关键时刻：**

```
候选人3：
- 期望20K
- 表明"更看重成长空间，薪资可以适当让步"
状态：++ （灵活且真诚）

公司6：
- 预算18K封顶
- HR说："你表现很好，我们很想要你，但预算确实只有18K"
状态：+ （有意愿，但预算卡住）

态度线对照：++↔+ （候选人灵活，但存在差距）
```

**态度线的跳变：**

```
候选人的选择：
A. 坚持20K → 可能谈崩
B. 接受18K → 达成

候选人思考：
"行动线表现很好，公司也很满意（++↔++）
素质线被重估，我有筹码（++↔+）
但态度线有差距，如果坚持可能崩盘
18K也能接受，成长空间更重要"

决定：接受18K

态度线对照：++↔++ （达成共识）
```

**最终结构（Offer发出）：**

```
素质线：++↔+ （候选人通过行动线被高估）
行动线：++↔++ （双方都满意）
态度线：++↔++ （达成一致）

结果：Offer发出，候选人接受
```

### 3.4 三条线的协同与跳变

**协同1：行动线补素质线**

```
初始：素质线略有不足（+↔+）
    ↓
行动线超强（++）
    ↓
素质线被重估（++↔+）
    ↓
候选人筹码增加
```

**协同2：行动线为态度线铺路**

```
行动线表现好（++↔++）
    ↓
公司"很想要你"
    ↓
态度线谈判时，候选人有底气
    ↓
最终即使有gap，也能协商
```

**跳变点：态度线的灵活性**

```
如果候选人坚持20K：

态度线：++↔+ → --↔- （冲突）
    ↓
即使前两线再好
    ↓
最终崩盘

候选人选择18K：

态度线：++↔+ → ++↔++ （共识）
    ↓
三线全通
    ↓
达成
```

**关键洞察：**

**面试是2↔5的强制互动，但最终拍板在3↔6。**

如果态度线冲突，前两线再好也会崩。

### 3.5 从锚定镜像法看面试

**为什么锚定候选人在行动线2有效？**

因为这个视角**直接抓住了面试的本质**：

```
面试 = 候选人展示（2）↔ 公司考察（5）

其他两线是辅助：
- 素质线（1↔4）：前提条件
- 态度线（3↔6）：最终拍板
```

**如果用主客并行法：**

```
主体（我）：1-2-3
客体（公司）：4-5-6

需要六维全展开，才能看清
```

**用锚定镜像法：**

```
锚定候选人在2 → 公司自动在5
主线：行动线（2↔5）
辅助：素质线（1↔4）、态度线（3↔6）

一目了然
```

**这就是锚定镜像法的价值：快速聚焦主线。**

## 第四节：操作方法

基于面试案例，我们可以提炼出锚定镜像法的操作要点。

### 4.1 三个阶段的策略

#### 进场前：补足素质线

**素质线是前提，必须达到最低标准。**

**操作要点：**

1. **对齐关键词**
    
    - 简历与岗位要求的关键词匹配
    - 用对方的语言描述自己的经验
2. **准备证明材料**
    
    - 作品集、项目案例
    - 量化成果（数据说话）
3. **降低预期差距**
    
    - 如果素质线明显不足，提前说明"为什么我能胜任"
    - 不要让对方在面试中才发现gap

**面试案例：**

张三提前准备：

- 简历突出"独立负责2个项目"（对齐岗位要求）
- 作品集包含详细的产品逻辑（证明能力）
- 在简历中说明"虽然只有3年经验，但项目复杂度高"（降低预期差距）

**素质线补到+以上，才有资格进入行动线博弈。**

#### 面试中：抓住行动线

**行动线是主战场，决定素质线的重估。**

**操作要点：**

1. **顺着对方的节奏**
    
    - 公司在5（考察），我在2（展示）
    - 不要打乱对方的提问节奏
    - 回答要切中要点
2. **展示而非推销**
    
    - 用案例说话，而非空话
    - 让对方自己得出"这个人不错"的结论
3. **双向互动**
    
    - 不是单向回答
    - 适当提问，展示兴趣和思考
4. **观察反馈，调整策略**
    
    - 如果对方频频点头→继续深入
    - 如果对方皱眉→换个角度或简化

**面试案例：**

张三的操作：

- 面试官问项目细节→用STAR法则回答（Situation-Task-Action-Result）
- 展示作品集时，不是"我做了什么"，而是"这个产品解决了什么问题"
- 主动问"团队现在的挑战是什么"→展示真诚兴趣

**行动线表现好，可以把素质线从+拉到++。**

#### 结尾时：处理态度线

**态度线是最终拍板，要展现契合度和灵活性。**

**操作要点：**

1. **明确期望，但保持灵活**
    
    - 说出自己的期望（薪资、成长）
    - 但表明"可以讨论"
2. **强调价值观契合**
    
    - "我看重的是___，这和贵司的文化一致"
    - 让对方觉得"这个人适合我们"
3. **给台阶，别把天聊死**
    
    - 如果有gap，不要直接拒绝
    - 可以说"我需要考虑一下"
4. **观察对方的预算空间**
    
    - 如果对方说"预算就这么多"→可能真没空间
    - 如果对方说"我再争取一下"→有空间

**面试案例：**

张三的操作：

- "我期望20K，但更看重成长空间"（明确期望，保持灵活）
- "我很认同贵司的快速迭代文化"（价值观契合）
- 当HR说只有18K时，没有立即拒绝，而是说"这个薪资比预期低一点，但如果有明确的成长路径，我可以接受"（给台阶）

**态度线处理好，才能最终达成。**

### 4.2 三条线的调度策略

**核心原则：用优势线补弱势线。**

#### 策略1：行动线补素质线

```
素质线不足（+）
    ↓
行动线超强（++）
    ↓
让对方重估素质线
    ↓
"虽然经验少，但能力强"
```

**适用场景：**

- 新人求职（经验不足，但潜力强）
- 转行者（背景不匹配，但学习能力强）

#### 策略2：素质线撑行动线

```
素质线超强（++）
    ↓
行动线一般（+）
    ↓
凭素质也能过关
    ↓
"名校背景/大厂经验"
```

**适用场景：**

- 高端人才（背景硬，不需要过度展示）
- 稀缺岗位（供小于求）

#### 策略3：态度线救场

```
前两线都一般（+）
    ↓
态度线超强（++）
    ↓
"我非常想来，可以接受低于市场的薪资"
    ↓
对方被诚意打动
```

**适用场景：**

- 特别想进某家公司
- 岗位竞争激烈

#### 策略4：止损策略

```
三条线至少保一条（++）
    ↓
其他两条可以适度妥协
    ↓
但如果三条都是（-）
    ↓
不如主动放弃
```

**底线：**

- 素质线（-）+ 行动线（-）+ 态度线（-）= 必败
- 至少保证一条线强，才有谈判空间

### 4.3 实战检查清单

```
【面试前检查】

□ 素质线（1↔4）
  □ 简历关键词是否对齐岗位要求？
  □ 是否准备了证明材料（作品/案例）？
  □ 是否有明显短板？如何弥补？

□ 行动线（2↔5）
  □ 是否了解面试流程？
  □ 是否准备了常见问题的回答？
  □ 是否准备了要问对方的问题？

□ 态度线（3↔6）
  □ 是否明确自己的期望（薪资/成长）？
  □ 是否了解对方的文化和预算？
  □ 是否有妥协空间？底线在哪里？

【面试中观察】

□ 行动线反馈
  □ 对方是否频频点头/追问细节？（好信号）
  □ 对方是否皱眉/打断？（坏信号）
  □ 对方是否给正面反馈？（好信号）

□ 素质线重估
  □ 对方是否说"你的经验比简历看起来丰富"？（被拉高）
  □ 对方是否说"这个项目不算复杂"？（被拉低）

□ 态度线试探
  □ 对方是否主动谈薪资？（有意向）
  □ 对方是否问"你还在面试其他公司吗"？（想确认）

【面试后复盘】

□ 三条线的实际状态
  素质线：___ （是否如预期？）
  行动线：___ （表现如何？哪里可以更好？）
  态度线：___ （是否展现了契合度？）

□ 如果没通过，卡在哪条线？
  □ 素质线（经验/能力不够）
  □ 行动线（表现失常/没说清楚）
  □ 态度线（期望不匹配/文化不合）

□ 下次改进
  ___
```

## 第五节：方法论总结

### 5.1 何时用并行、何时用锚定

**使用决策树：**

```
问题1：我是参与者吗？

是 → 问题2
否 → 用第三方视角（第十四章）

问题2：我的立场明确吗？

是 → 用主客并行法
否 → 问题3

问题3：谁是局面的发起方？

明确 → 用锚定镜像法（锚定发起方）
不明确 → 先判断发起方，再决定

问题4：需要强调主导性吗？

是 → 用锚定镜像法
否 → 用主客并行法
```

**简化版：**

|场景|推荐方法|理由|
|---|---|---|
|我明确是主体，要指导自己行动|主客并行法|立场清晰|
|我是外部观察者|第三方视角|不是参与者|
|需要快速判断谁主导|锚定镜像法|强调起点偏置|
|需要强调某条对照线|锚定镜像法|三线结构更清晰|
|需要全面分析六维|主客并行法|对称展开更完整|
|面试、推销、谈判等"一方主动"|锚定镜像法|自然锚定发起方|

**两种方法可以结合：**

```
第一步：用锚定镜像法快速切入
    ↓
确定主线（行动线/素质线/态度线）
    ↓
第二步：用主客并行法深入分析
    ↓
展开完整六维，细化每个维度
```

### 5.2 锚定镜像法的适用范围

**适合的场景：**

1. **明确有"主动方"的局面**
    
    - 面试（候选人主动）
    - 推销（销售主动）
    - 谈判（提条件方主动）
    - 追求（追求者主动）
2. **需要强调"主导性"**
    
    - 谁在主导这个局面？
    - 谁的行动更关键？
3. **需要"快速聚焦"**
    
    - 不需要六维全展开
    - 抓住主线即可

**不适合的场景：**

1. **双方地位完全对等**
    
    - 平等合作
    - 双向选择（都不是明确的发起方）
2. **需要全面分析**
    
    - 复杂的战略决策
    - 需要逐维度细致分析
3. **我的立场很明确**
    
    - 我就是主体，直接用主客并行法更自然

###  5.3 结构语言的开放性

**核心认知：**

结构语言不是一个封闭的公理系统，而是一个**开放的工具箱**。

**已有的方法：**

- 主客并行法（第五章）
- 第三方视角（第十四章）
- 上下分组（第十四章）
- 基础-互动-目标（第十四章）
- 锚定镜像法（本章）
- 其他你自己创造的新方法

**关键原则：**

**不是"哪种方法正确"，而是"哪种方法适合当前意图"。**

就像同一个立方体：

- 从正面看，是正方形
- 从侧面看，是正方形
- 从角上看，是六边形

**六维结构就是那个立方体，不同方法就是不同的观察角度。**

**结构语言关心的不是你怎么搭，而是搭出来的结构能不能解释局势、指导动作。**

### 5.4 方法的选择与组合

**单一方法：**

- 简单场景：选一种方法即可
- 面试、推销→锚定镜像法
- 我的决策→主客并行法
- 观察外部→第三方视角

**组合方法：**

- 复杂场景：多种方法结合

**示例：外部结构影响我的局面**

```
第一步：用第三方视角分析外部结构
    ↓
A公司和B公司在谈判（上下分组：-+，失衡结构）
    ↓
第二步：用主客并行法分析我的局面
    ↓
我（主体）vs B（客体）
    ↓
第三步：预测外部结构影响我的哪个维度
    ↓
调整策略
```

**示例：我要主动出击的局面**

```
第一步：用锚定镜像法快速定位
    ↓
我是发起方，锚定在行动线2
    ↓
第二步：用主客并行法细化
    ↓
展开六维，制定详细策略
    ↓
第三步：执行并监控
```

**方法的选择和组合，取决于：**

1. 当前意图
2. 信息充分程度
3. 时间窗口
4. 个人习惯

**没有绝对的"最优方法"，只有"适合当下"的方法。**

## 结语：工具箱而非教条

这一章，我们介绍了锚定镜像结构——一种不同于主客并行的建立方式。

**核心要点：**

1. **锚定→镜像的机制**
    
    - 先固定主方位置
    - 对方自动对位
    - 谁先被锚定，谁主导解释路径
2. **三条对照线**
    
    - 素质线（1↔4）：前提条件
    - 行动线（2↔5）：主战场
    - 态度线（3↔6）：最终拍板
3. **面试局的完整展示**
    
    - 锚定候选人在行动线2
    - 三条线协同与跳变
    - 操作方法与检查清单
4. **方法的选择**
    
    - 不是对立，而是互补
    - 根据意图选择方法
    - 可以组合使用

**最重要的认知：**

**结构语言是一个开放的工具箱，不是封闭的教条。**

- 你可以用主客并行法
- 你可以用锚定镜像法
- 你可以用第三方视角
- 你甚至可以创造新的分组方式

**只要它能帮你：**

- 解释局势
- 指导行动
- 在实践中验证有效

**那它就是好方法。**


**下一章预告：**

- 如何与错误共舞，在修正中进化？

所有操作方法都在进化中修正。认知进化是自然过程，但在社会中，认知也会被操控。

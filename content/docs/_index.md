## 🚀 Understanding StructLang

StructLang is a cognitive language system that makes **thinking structural, judgments visible, and strategies computable**.  
It aims to reveal the **multi-layered structural logic** behind human cognition, decision-making, and interaction.

> StructLang does not regard thought as a linear process.  
> It is a continuously **recursive system**: **Intention → Compression → Structure → Shift → Consensus → New Intention**.  
> Each stage can become the starting point for the next round of cognition.
